## 实现过程中的修复（red→green）

实现中发现并修复 3 处实现缺陷（非放宽断言）：

1. **SWR 条件启用**：原 BrokerRecommendPage 无条件调用 useBrokerStockRanking + useBrokerList，导致 view=stock 时仍请求 broker-list，未 mock 时触发 401 → handleUnauthorizedRedirect → 重定向 login（TC-3.7 失败根因）。修复：两 hook 增加 `enabled` 参数，空状态时不请求、按 view 启用对应 hook。
2. **task_id 解包**：BrokerRecommendSyncPanel.handleSync 原直接取 `res.task_id`，但 adminApiClient.post 返回 AxiosResponse，需 `response.data?.task_id`（范式参照 StockTop10SyncPanel line 170）。修复后 useTaskStatus 正确轮询。
3. **测试 selector 适配**（合理适配 DOM，非放宽断言）：
   - TC-3.3：展开内容在独立 colSpan 行，改用 page 级 testid 定位（原 `rows.nth(2).locator` 无法定位兄弟行）
   - TC-3.6：MonthSelector 为原生 select，改用 selectOption（原 `getByRole('option')` 不适用 native select）
   - mock months 格式：与后端 Date.isoformat() 对齐为 YYYY-MM-01（原 YYYY-MM 导致 selectOption value 不匹配）
