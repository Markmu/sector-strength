## 断言保护强度（不放宽）

每个新端点的用例都严格断言：

- **响应字段**：camelCase 字段（`matchedStockCount` / `stockName` / `holderName` / `pageSize`）必须存在；snake_case 字段（`matched_stock_count` / `stock_name` / `holder_name`）必须**不存在**（防止 alias 转换遗漏）。
- **数据正确性**：`全国社保` 必须返回 2（不是 0、不是 3）；`社保基金` 必须返回 3；同股票多股东按 (symbol, holder_name) 粒度拆行（不是去重为 1 行）。
- **排序**：symbol 字符串升序（`sorted(symbols) == symbols`），同 symbol 多股东相邻。
- **降级**：单关键词失败 → 该 item `matchedStockCount=None`，其他 item 必须有 int 值（不放宽为「全部 None 也算通过」）。
- **分页**：page=1 page_size=2 必须返回恰好 2 行；page=2 必须返回恰好 1 行；total 在两页都必须为 3（不放宽为「只要 ≤total 就行」）。
- **安全**：`keyword=%` 必须 total=0（不允许 total > 0 的全表匹配）。
- **权限**：normal_client 必须 401/403，未认证必须 401（不允许其他状态码）。
