# plan-03 E2E Green 证据：股票读取路径切换

## 1. 摘要

plan-03 已由 implementer 推进到 `review`。本证据验证所有 `entity_type='stock'` 的读取路径已切换到新三表（`stock_daily_market_data` / `stock_moving_average_data` / `stock_strength_scores`），个股接口返回新表数据（AC-02），空窗期呈现正确（AC-07），percentile 列可正常写入新表，板块路径零回归（AC-03 硬门禁通过）。

**结论：通过**

## 2. 验证范围

本功能是纯后端数据存储层读路径改造（无前端 UI 变化）。按 README §7.2 说明，green 验证对应 pytest 通过 + SQLAlchemy 直查验证。

验证维度：
1. **代码核查**：10 个目标文件的所有 stock 读路径已切新表
2. **AC-02 实测**：个股强度查询 / 个股排名 v2 内部 select 命中新表
3. **AC-07 实测**：新表无 ma240 数据时 `load_ma_values` 返回 dict 不含 240 键
4. **percentile 实测**：触发排名计算后 `stock_strength_scores.percentile` 非空（无 "column does not exist" 错误）
5. **AC-03 板块门禁**：板块相关 pytest 零回归（44/44 硬门禁）

### 3.2 AC-02 实测（个股接口读新表）

SQLAlchemy 直查模拟 stocks.py / rankings.py 的查询：

```
[AC-02] stocks.py strength query (StockStrengthScoreModel): found stock_id=999950, score=55.5000
[AC-02] -> PASS (reads new table stock_strength_scores)
[AC-02] rankings v2 stocks join query syntax correct (StockStrengthScoreModel join Stock on stock_id)
```

- `stocks.py` 的 `select(StockStrengthScoreModel).where(stock_id == stock.id)` 直接命中 `stock_strength_scores` 表
- `rankings.py` v2 的 `select(StockStrengthScoreModel, StockModel).join(StockModel, stock_id == StockModel.id)` 语法正确

### 3.3 AC-07 实测（空窗期呈现）

向 `stock_moving_average_data` 插入 5d/10d/20d 周期数据（无 240d），调用 `load_ma_values`：

```
[AC-07] load_ma_values returned keys: [5, 10, 20]
[AC-07] contains 240: False  -> PASS (empty window: 240 absent, caller shows "insufficient data")
```

- 返回 dict 不含 240 键 → 调用方按既有"数据不足"方式呈现，前端零改动

### 3.4 percentile 列写入实测（ADR-3 关键风险）

向 `stock_strength_scores` 插入 3 条测试数据（score=80/60/40），调 `RankingService.calculate_rankings(entity_types=['stock'])`：

```
[RANK] success=True, results={'stock': {'total': 3, 'ranked': 3, 'unranked': 0}}
[PERCENTILE] rows (stock_id, score, rank, percentile):
   (999901, Decimal('80.0000'), 1, Decimal('66.6700'))
   (999902, Decimal('60.0000'), 2, Decimal('33.3300'))
   (999903, Decimal('40.0000'), 3, Decimal('0.0000'))
[PERCENTILE] any non-null: True  -> PASS (percentile column writable, no "column does not exist" error)
```

- `ranking_service.py:91` 的 `score.percentile = round((1 - rank / total) * 100, 2)` 成功写入 `stock_strength_scores.percentile` 列
- rank 与 percentile 计算正确（score 80 → rank 1 → percentile 66.67%）
- 无 "column does not exist" 错误（plan-01 迁移含 percentile 列，ADR-3 落地）
