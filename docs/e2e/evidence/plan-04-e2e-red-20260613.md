### 失败根因分析

所有 10 个用例的失败根因一致：**plan-04 前端功能完全未实现**，对应文件全部不存在：

1. `web/src/app/dashboard/shareholder-analysis/page.tsx` — 不存在（访问该路由返回 HTTP 404，curl 实测确认）
2. `web/src/components/shareholder-analysis/ShareholderAnalysisPage.tsx`（及其余 6 个子组件）— 整个 `components/shareholder-analysis/` 目录不存在
3. `web/src/components/dashboard/DashboardLayout.tsx` baseSidebarItems — 未新增「股东分析」项（error-context.md 快照显示现有侧边栏仅含 4 项 navigation link：强度分析/板块分析/板块强弱分类/基金分析）
4. `web/src/hooks/useShareholderAnalysis.ts` — 不存在
5. `web/src/lib/api.ts` shareholderAnalysisApi 对象 — 未新增

**关键区分证据**（确认非环境/选择器错误）：

- **TC-4.1** 访问 `/dashboard`（HTTP 200），侧边栏 `<aside>` 正常渲染，error-context.md yaml 快照解析出完整 navigation 结构（heading "板块强度" + button + navigation 含 4 个 link + 用户段落 + 退出登录按钮），说明页面加载正常、测试基础链路（dev server、Playwright、登录注入 `authedPage` fixture、localStorage+Cookie 双注入）均工作；失败纯粹因缺「股东分析」导航项 link。定位精准到 `getByRole('link', { name: '股东分析' })` element not found，符合规则 5/7 推荐写法，无歧义。
- **TC-4.2 起**访问 `/dashboard/shareholder-analysis`，curl 实测返回 **HTTP 404**，对应 page.tsx 未创建，断言自然找不到卡片/表格/筛选器。
- TC-4.9（空状态用例）的失败是 `getByText(/暂无股东数据|暂无数据/)` element not found，而非页面崩溃——说明 404 页面被 Next.js 兜底渲染但不含目标文案，符合「组件未实现」预期。

失败原因不属于以下任一类（即满足 red 原则）：

- ❌ 测试代码语法错误（spec 被 `--list` 完整收集 10 个用例，无解析错误）
- ❌ 环境错误（dev server 200 就绪，Playwright 1.60.0 + chromium 就绪，shareholder-groups.spec.ts / fund-detail.spec.ts 同环境可跑）
- ❌ 选择器错误（TC-4.1 用 `getByRole('link', { name })` 精确定位，是规则 5/7 推荐写法；失败因目标元素不存在，不是匹配到多个）
