# plan-07 E2E Red 证据：首页市场量价面板（16 期）

## 结论

**预期失败，测试有效。**

- plan-07「首页市场量价面板」是用户可观察的 mixed 功能（MarketMetricsPanel 组件插入管理员首页与普通首页），用 **Playwright E2E red 测试**。前置 plan-06 已 done。
- plan-07 范围的 **8 个用例（TC-7.1~7.8）全部失败**，失败原因均为「MarketMetricsPanel 组件尚未实现」：`market-metrics-panel` 及其内部 testid（chart / metric 按钮组 / range 按钮组 / missing-hint / empty / error / retry 等）全部不存在 → `element(s) not found`（10.2s）。
- spec 文件可被 Playwright 正常收集（8 tests，0 passed + 8 failed，0 skipped），无编译错误、无 import 错误——失败完全来自被测功能缺失，符合 red 关键原则。
- **环境已就绪**：dev server（3100）返回 200，后端（8000）运行中（测试用 mock 不依赖真实后端数据）。认证 fixture（admin/user 两套 localStorage + cookie）、宿主页 mock 均生效，**两套首页正常渲染**（管理员：关键指数监控 + 指数总览；普通：基金分析快捷入口 + 市场强度指数），无 /login 重定向——8 个失败只能归因于 plan-07 待实现（MarketMetricsPanel 组件 + 两处首页插入）。

## 测试设计要点

- **red 失败原因落在「组件未实现」**：每个用例首个断言为 `market-metrics-panel`（或 empty/error 容器）可见 → 组件不存在即 10.2s 内失败，避免 30s click 超时
- **mock 数据让 AC 断言有意义**：
  - 满数据：amountYuan ~8200 亿、volumeShares ~720 亿股、averagePrice ~11.38（股/元原始值，覆盖 ÷1e8 显示层换算）
  - 缺口：7 日轴索引 2/4 为 null（非 0），hasMissingDates=true（验证 connectNulls:false 断线 + 提示）
  - 全空：latest=null（验证管理员链接 / 普通文案两态）
- **宿主页稳定（关键修复）**：AuthContext 首帧 user=null → isAdmin=false → /dashboard 短暂渲染普通分支并发起 market-index/heatmap/rankings；用 mock token 打真实后端（8000 在线）会 401 触发 `handleUnauthorizedRedirect` 跳 /login。admin beforeEach 一并装 `mockNormalDashboardPrerequisites` 消除该竞态重定向（首轮 8/8 均 navigated to /login → 修复后 8/8 均正常渲染宿主页，失败原因转为 testid not found）
- **与时钟/真实后端解耦**：全部用 `page.route` mock，dev server（3100）仅需可达，后端（8000）数据无关
- **testid 命名约定**（供 plan-07 实现者参照）：见用例文档「data-testid 清单」，前缀 `market-metrics-`
