## 5. 关键断言说明

### 5.1 视图切换 / 排序（aria-selected）

视图切换按钮（`fund-flow-view-ranking` / `fund-flow-view-chart`）使用 `aria-selected` 反映选中态，spec 用 `toHaveAttribute('aria-selected', 'true')` 断言。

排序表头（`fund-flow-sort-net_inflow` / `fund-flow-sort-inflow` / `fund-flow-sort-outflow`）点击切换 `sortBy` + `order`，spec 通过表格首行板块名变化佐证排序生效（mock handler 内按 query 重排）。

### 5.2 维度切换（数据联动佐证）

`sector-type` 按钮无 `aria-*` 属性（仅 class 区分激活态，与 fund-crowd 的 `aria-pressed` 不同）。spec 通过表格首行板块名变化（industry→半导体 / concept→新能源）佐证维度切换生效，而非 aria 断言。

### 5.3 盘中变化曲线（双态切换）

- 未选板块 → `fund-flow-timeseries-guide` 引导态可见（AC-05，不画空坐标系）
- 选板块后 → `fund-flow-timeseries-chart` 渲染（mock 按 `sector_names` 返回对应曲线）
- 已选板块 chip 区 `fund-flow-selected-sectors` + 可移除按钮 `fund-flow-remove-sector-{name}` 验证 AC-06

### 5.4 错误态独立降级（AC-09）

rankings 返回 500 → `fund-flow-ranking-error` + `fund-flow-ranking-retry` 可见，表格数据行 count=0；timeseries / latest-date 仍正常（独立降级，互不影响）。
