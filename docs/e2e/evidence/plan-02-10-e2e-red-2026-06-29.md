# plan-02 E2E Red 证据（10 需求 · 前端推荐趋势视图）

## 结论

**预期失败，测试有效。**

- 前端 FEAT plan-02（10 期前端推荐趋势视图：ViewSwitcher 第三选项 `broker-view-trend` + 趋势榜表格 `broker-trend-table` + Sparkline `broker-trend-sparkline-{symbol}` + 行展开月度明细 + 分页 + 搜索 + 状态机改造）尚未实现。
- 新增 **14 个 E2E 用例，13 个失败 / 1 个通过**，全部因「趋势视图元素尚未实现」失败：
  - **`getByTestId('broker-view-trend')` → element(s) not found**（13 例）—— 视图切换器尚未加 `trend` 第三项，所有依赖切换到趋势视图的用例在第一步 `.click()` / `.toBeVisible()` 即失败。
  - 后续依赖的 `broker-trend-table` / `broker-trend-sparkline-{symbol}` / `broker-trend-expand-{symbol}` / `broker-trend-expand-content-{symbol}` / `broker-trend-pagination` 同样均不存在。
- 测试文件可被 Playwright 正常收集与执行（**14 tests collected & run**），无 ImportError、无 collection error、无语法错误、无 mock 注册失败、无环境错误——失败完全来自功能未实现，符合 red 关键原则。
- **唯一通过用例 TC-2.14（空状态 AC-12）**：复用 09 既有 `hasNoData` 整页空状态行为（空状态时本就不渲染视图切换器、`broker-view-trend` count=0 断言成立）。这是正确的 red 局部——它验证的是「空状态下趋势视图同样不展示」的既有边界，而非本期新行为，实现后仍应通过（既不阻塞 red，也不阻塞 green）。
