## 关键验证点（green 阶段确认的行为）

1. **多选去重（AC-03 / US-06）**：依次点击「国家队」+「外资投行」卡片后，holdings 表格展示去重后的 5 只股票（含外资投行独有的招商银行 600036），且 601398（工商银行，两组都匹配）仅出现 1 行。去重在 API 侧完成（plan-02 后端去重），前端正确展示。
2. **行业筛选联动（AC-04）**：筛选栏行业下拉选「银行」→ 列表仅显示行业含「银行」的股票（601398 工商银行），白酒股（600519 贵州茅台）被过滤；同时 summary 请求带 industry 参数联动更新汇总统计。行业分布图点击「银行」条目同样触发筛选栏联动 + 列表过滤。
3. **变动方向筛选含「退出」（AC-05 / US-07）**：变动方向下拉选「退出」→ 列表展示退出股票（600000 浦发银行，changeDirection=exit），并展示其上期持股数据（600 股）。退出股票的渲染路径（「上期有本期无」）正确实现。
4. **报告期切换清空选中（AC-09）**：切换报告期下拉到 2024-09-30 后，选中监控组被清空，详情区恢复「请选择监控组」提示，overview 重新请求新报告期数据。
5. **空状态（AC-08 / L3）**：overview 返回空 report_periods + 空 groups 时，全页展示「暂无股东数据」提示，且不渲染监控组卡片和持仓表格（`main.locator('table')` 计数为 0）。
6. **降级提示（AC-11 / L2）**：hasPrevPeriod=false 时，变动趋势区域展示「暂不可用」提示，持仓股票列表「较上期」列显示「—」（changeDirection 渲染为 null 的退化符号）。
