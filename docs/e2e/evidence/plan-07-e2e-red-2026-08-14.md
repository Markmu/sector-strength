## 测试设计要点（含 1 项需 implementer 配合的测试钩子）

- **red 失败原因落在「组件未实现」**：每个用例首个断言为 `margin-panel`（或 error/empty 容器）可见 → 组件不存在即 10s 内失败，不会走到 30s click 超时
- **mock 未命中的预防**：路由匹配用 `matchApiPath(url, '/api/v1/margin/trend')`（URL.pathname 精确匹配、host 无关、query 不影响），前端 endpoint 与 baseURL 拼接为 `/api/v1/margin/trend`（四件套校验结论：无双前缀）——实测 market-metrics 相邻面板 mock 命中（快照见上），路由链路同构
- **ECharts option 读取钩子（唯一新增约定）**：ECharts 实例注册表在 echarts 模块闭包内（`window.echarts` 不存在、canvas 文案不在 DOM），legend 内容与 series null/0 无法从 DOM 断言。约定 implementer 在 `MarginPanel` 的 `onChartReady` 把实例挂到 `margin-chart` 容器（`(el as any).__echartsInst__ = chart`），spec 经 `readChartOption` 读 `getOption()`；该钩子已写入用例文档「data-testid / 测试钩子清单」，jest 组件测试同源互补
- **宿主页稳定**：beforeEach 复用 16 期 `mockNormalDashboardPrerequisites`（market-index/heatmap/rankings）+ `mockMarketMetricsTrend`（相邻面板），避免 mock token 打真实后端 401 → `handleUnauthorizedRedirect` 跳 /login 污染失败原因
- **已知无害噪音**：快照中「市场强度指数」区块显示「加载市场指数失败」——该 tile 为 mock 空数据的降级展示，不触发重定向、不影响断言（与 16 期 spec 同一 helper 行为一致）
