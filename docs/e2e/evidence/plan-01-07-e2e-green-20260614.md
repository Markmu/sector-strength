## 断言保护强度（不放宽校验）

每个新端点用例的断言严格遵循 red 阶段证据 §「断言保护强度（不放宽）」要求，green 阶段全部满足：

- **响应字段**：camelCase 字段（`matchedStockCount` / `stockName` / `holderName` / `pageSize`）存在；snake_case 字段不存在（Pydantic alias 转换生效）。
- **数据正确性**：单关键词股数（全国社保 → 2、社保基金 → 3）；同股票多股东按 (symbol, holder_name) 粒度拆行。
- **排序**：symbol 字符串升序 + 同 symbol 多股东相邻。
- **降级**：单关键词失败 → 该 item `matchedStockCount=None`，其他 item 必须有 int 值。
- **分页**：page=1 page_size=2 必须返回恰好对应行数，total 在两页保持一致。
- **安全**：`keyword=%` 必须 total=0（LIKE 通配符被 `_escape_like_keyword` 转义）。
- **权限**：normal_client 必须 401/403，未认证必须 401。

**`test_keyword_matches_pagination` total 调整说明**（主 agent 已核查）：fixture 中 `000001 社保基金理事会` 包含「社保基金」字面，应被 `_get_keyword_matches("社保基金", ...)` 匹配。因此调 `?keyword=社保基金` 时 total 应为 4（600000×2 + 600036 + 000001），而非 3。该调整为反映真实匹配语义的修正，**非断言放宽**。
