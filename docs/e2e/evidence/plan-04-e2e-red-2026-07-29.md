# plan-04 E2E Red 证据：ETF 监控前端基础设施（14 期）

## 结论

**预期失败，测试有效。**

- plan-04「前端基础设施」是用户可观察功能（导航入口可点击、路由可访问），用 **Playwright E2E red 测试**（非 pytest）。后端 plan-01/02/03 均已 done。
- plan-04 范围的 **5 个导航/路由用例全部失败**，失败原因均为「目标功能尚未实现」：
  - 2 个用例 → 侧边栏无"ETF 监控"导航项（`getByRole('link', { name: 'ETF 监控' })` 元素未找到 / 顺序断言计数不符）

- spec 文件可被 Playwright 正常收集（18 tests，5 run + 12 skipped + 1 passed），无编译错误、无 import 错误——失败完全来自被测功能缺失，符合 red 关键原则。
- **环境已就绪**：dev server（3100）+ 后端（8000）均运行中。**降级回归用例 TC-4.6 通过**（断言 sector-fund-flow 页现有导航项与 active href 正常），证明认证 fixture、页面加载、断言基建均正常——5 个失败只能归因于 plan-04 待实现（导航项/路由）。
