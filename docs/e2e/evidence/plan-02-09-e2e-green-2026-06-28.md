## 实现要点

- **search 防注入**：股票维度 `symbol.like(escaped + "%") OR Stock.name.ilike("%" + escaped + "%")`，券商维度 `broker.ilike("%" + escaped + "%")`，均用 `_escape_like_keyword` 转义 %/_
- **AC-07 双字段排序**：股票 `broker_count DESC, symbol ASC`；券商 `stock_count DESC, broker ASC`
- **AC-10 默认月份**：`get_latest_month()` = `MAX(month)`（YYYYMM 值最大者）
- **AC-03 brokers 预加载**：`get_stock_brokers` 批量获取，service `_aggregate_brokers` 同券商多 reason 归并为 `{broker, reasons:[]}`，LIMIT 100 兜底
- **AC-13 broker 精确匹配**：`get_broker_detail` 用 `==` 不做 LIKE；同 symbol 多 reason 合并去空去重
- **AC-09 空状态**：表无数据 `get_latest_month()` 返回 None → `has_data: False`
