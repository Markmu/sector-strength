## 关键实现决策

1. **displayResult 三级回退**：`terminalResult ?? task?.result ?? recordResult`。本地任务终态由 useTaskStatus `onComplete` 回调写入 `terminalResult`；同时 `task` 保留终态（含 result）作回退（jest 全量 mock useTaskStatus 不触发回调时仍可断言）；无本地任务时取最近一条带 result 的记录（TC-8.7/8.8 直接从历史记录展示 dateResults）。
2. **AdminApiClient `success=false` 抛错**：HTTP 200 但业务 `success===false`（init 互斥/校验拒绝）时抛 `message`。严格 `=== false` 判定，不返回 success 字段的端点不受影响。经 admin-etf-sync 12/12 回归确认安全（ETF 并发保护 mock 同样返回 success=false，改后展示真实 message 更优）。
3. **互斥双信号**：记录列表含 pending/running 同类任务 → `mutex-hint` 提示 + 按钮禁用（TC-8.6）；本地任务运行 → 按钮显示「同步中…」；后端二次拒绝 → `validation-error` 展示 message（TC-8.10，前端禁用不承担一致性）。
4. **result 大对象护栏**：dateResults 仅渲染最近 50 条 + 「加载更多」懒加载（plan §风险备注），reason 截断 100 字符（title 保留全文）。
