### 失败根因分析

所有 11 个用例的失败根因一致：**plan-03 前端功能完全未实现**，对应文件全部不存在：

1. `web/src/app/dashboard/admin/shareholder-groups/page.tsx` — 不存在（访问该路由返回 HTTP 404，curl 实测确认）
2. `web/src/components/admin/ShareholderGroupPanel.tsx` — 不存在
3. `web/src/components/admin/AdminSidebar.tsx` navItems — 未新增「股东分组管理」项（error-context.yaml 快照显示现有侧边栏仅含 6 项：仪表板/数据管理/任务监控/基金同步/股票持仓同步/用户管理）
4. `web/src/lib/api.ts` adminApi — 未新增 shareholder 分组相关方法（grep 实测确认）

**关键区分证据**（确认非环境/选择器错误）：

- TC-1.1 访问 `/dashboard/admin`（HTTP 200），侧边栏 `<aside>` 正常渲染并解析出完整 navigation 结构（见失败快照 yaml），说明页面加载正常、测试基础链路（dev server、Playwright、登录注入）均工作；失败纯粹因缺「股东分组管理」导航项 link。
- TC-1.2 起访问 `/dashboard/admin/shareholder-groups`，curl 实测返回 **HTTP 404**，对应 page.tsx 未创建，断言自然找不到 table/按钮/dialog。
- TC-1.1 的失败定位精准到 `getByRole('link', { name: '股东分组管理' })` element not found，符合「导航项待新增」的预期，无歧义。

失败原因不属于以下任一类（即满足 red 原则）：

- ❌ 测试代码语法错误（spec 被 `--list` 完整收集 11 个用例，无解析错误）
- ❌ 环境错误（dev server 200 就绪，Playwright 1.60.0 + chromium 就绪，admin-fund-sync.spec.ts 同环境可跑）
- ❌ 选择器错误（TC-1.1 用 `getByRole('link', { name })` 精确定位，是规则 5/7 推荐写法；失败因目标元素不存在，不是匹配到多个）
