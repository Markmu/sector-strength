# E2E 测试用例：板块成分股列表

## 资产现状

- **Playwright projects**: `admin`（Desktop Chrome，端口 3100）
- **workers**: 1（遵循规则 6，UI 重型测试串行；`playwright.config.ts:13`）
- **baseURL**: `http://localhost:3100`
- **现有相关 spec**: `fund-crowd-analysis.spec.ts`（同类先例：authedPage fixture + 全量 mock 安装范式 + 表格+分页+三态断言）、`fund-reverse-lookup.spec.ts`（下钻跳转先例）
- **可复用 helpers 模式**: `mock-fund-crowd-api.ts`（matchApiPath pathname 精确匹配 + `route.fallback()` 防 LIFO 短路 + test data factory + 外层 `{ success, data }` 包裹）
- **认证 fixture**: `authedPage`（参照 `fund-crowd-analysis.spec.ts:22-53`：本项目自定义 JWT，localStorage `accessToken` + Cookie `access_token`，非 NextAuth；普通用户 `role: 'user'`）
- **后端 API 外层契约**: `{ success: true, data: {...} }`（成分股接口 `server/src/api/v1/sectors.py:254`、个股接口 `server/src/api/v1/stocks.py:159`）
- **dev server**: Next.js `pnpm dev` 端口 3100，手动启动（`playwright.config.ts` 无 webServer 配置，与 06/08 一致）

## 关键约定

- **响应字段命名**：snake_case（id/symbol/name/current_price/market_cap/strength_score/trend_direction），mock factory 严格按 snake_case 造数，**不用 camelCase**
- **分页响应 data 结构**：`{ items, total, page, page_size, total_pages }`（对齐 PaginatedData）
- **跳转参数**：成分股点击用 `item.id`（数据库主键），路由 `/dashboard/stock-analysis/{id}`
- **趋势数值含义**：trend_direction 1=上升/0=横盘/-1=下降
- **页面会触发图表请求**：进入 `/dashboard/sector-analysis/{id}` 会同时请求 strength-history 与 ma-history，E2E 须 mock 否则 401 重定向
