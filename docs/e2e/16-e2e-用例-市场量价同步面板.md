## 契约（plan-08 §1 / 架构 §7.2-7.3 同源）

```ts
// POST /api/v1/admin/init/market-metrics — body snake_case，返回 ApiResponse data.task_id
//   成功：{ success: true, data: { task_id }, message }
//   互斥/校验拒绝：{ success: false, data: null, message }（HTTP 200，AdminApiClient 抛错）

// GET /api/v1/admin/tasks/{task_id} — TaskData camelCase + result（camelCase，前端直消费）
interface TaskData {
  taskId: string
  taskType: 'sync_market_metrics'
  status: 'pending' | 'running' | 'completed' | 'failed' | 'cancelled'
  progress: number       // 已处理交易日
  total: number          // 交易日口径
  percent: number
  result?: MarketMetricsTaskResult | null
  errorMessage?: string
  createdAt: string
  // ...其余 AsyncTask camelCase 字段
}

interface MarketMetricsTaskResult {
  successCount: number
  skippedCount: number
  failedCount: number
  dateResults: MarketMetricsDateResult[]
  unprocessedDates: string[]   // 取消/超时/executor_restarted 恢复时可非空；完整处理范围时为空
}

interface MarketMetricsDateResult {
  tradeDate: string
  status: 'success' | 'failed'
  expected: number     // 应参与
  daily: number        // 当日日行情
  suspended: number    // 全天停牌
  final: number        // 最终参与
  reason?: string      // 失败原因（截断展示）
}

// GET /api/v1/admin/tasks?task_types=sync_market_metrics&page=1&page_size=20 — fetcher 解包
//   返回 { tasks: TaskData[], total, page }（tasks 携带 nullable result）
```

## 需要新增的 mock / fixture（本期在 helper 内生成，无独立 JSON fixture）

`web/tests/e2e/helpers/mock-market-metrics-sync-api.ts`：

- `mockMarketMetricsSyncSuccess(page, taskId)` — POST `/api/v1/admin/init/market-metrics` 成功（`{ success:true, data:{ task_id }, message }`）
- `mockMarketMetricsSyncMutex(page)` — POST init 互斥拒绝（`{ success:false, data:null, message:"已有市场量价任务在运行" }`，HTTP 200）
- `mockMarketMetricsSyncValidationReject(page, message)` — POST init 校验拒绝（`{ success:false, data:null, message }`，HTTP 200）
- `mockMarketMetricsTaskPollingSequence(page, taskId)` — GET `/api/v1/admin/tasks/{taskId}` 轮询序列：首次/前若干次返回 running（progress/total + current date），随后返回 completed（带 MarketMetricsTaskResult fixture：success/skipped/failed 三类计数 + dateResults[success+failed] + unprocessedDates）
- `mockMarketMetricsTaskCompletedWithResult(page, taskId, result)` — GET task 固定 completed + 自定义 result（供记录列表/失败日期展开用例）
- `mockMarketMetricsSyncRecords(page, records)` — GET `/api/v1/admin/tasks?task_types=sync_market_metrics&page=1&page_size=20` 同步记录列表（fetcher 解包 `{ tasks, total, page }`，每条 record 携带 camelCase result）
- `createTestMarketMetricsResult(opts?)` / `createTestSyncRecord(opts?)` — test data factory（result 字段 camelCase，dateResults 含 success+failed 各一，failed.reason 非空）
- `installMarketMetricsSyncMocks(page)` — 一键安装（POST 成功 + 轮询序列 + 空记录）
- 宿主页稳定 mock 复用：默认 Tab（DataStatusPanel）请求 `/api/v1/admin/data/status` —— spec 内直接复用 `mock-api.ts` 的 `mockDataStatusNormal`（避免 401 重定向）
