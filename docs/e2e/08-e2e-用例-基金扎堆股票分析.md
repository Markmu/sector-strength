### 需要新增的 mock helpers（`web/tests/e2e/helpers/mock-fund-crowd-api.ts`）

- `mockCrowdRankings(page, data?)` — mock `GET /api/v1/fund-crowd-analysis/rankings`（handler 内按 query 的 `scope`/`search` 模拟后端过滤：scope=all 时 fundCount 翻倍；search 命中按代码前缀 OR 名称包含不区分大小写）

- `mockCrowdIndustryDistribution(page, data?)` — mock `GET /api/v1/fund-crowd-analysis/industry-distribution`
- `mockCrowdIndustryDistributionEmpty(page)` — mock industry-distribution 返回 `distribution=[]`（AC-04 边界 + 配合 AC-07）
- Test data factories：
  - `createTestCrowdRankings({ hasPrevPeriod?: boolean })` — 构造 3 只（贵州茅台 286 +12 / 宁德时代 198 -8 / 中芯国际 45 isNew=true）；`hasPrevPeriod=false` 时所有 change 字段与 isNew 统一 null（AC-06）

  - `createTestCrowdIndustryDistribution()` — 含食品饮料 16% / 电力设备 14% / 银行 10%

**注意**：2 个端点都用 `matchApiPath` pathname 精确匹配 + 非自己负责的方法调 `route.fallback()`，避免 LIFO 短路（参照 `mock-shareholder-analysis-api.ts` 注释）。
