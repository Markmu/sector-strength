### mock helpers（`web/tests/e2e/helpers/mock-sector-fund-flow-api.ts`）

- `mockFundFlowRankings(page, data?)` — mock `GET /api/v1/sector-fund-flow/rankings`（handler 按 query `sector_type`/`sort_by`/`order` 模拟维度切换与排序）
- `mockFundFlowRankingsError(page)` — mock rankings 返回 500（AC-09 错误态）
- `mockFundFlowRankingsEmpty(page)` — mock rankings 返回 `hasData=false`（空态）
- `mockFundFlowTimeseries(page, data?)` — mock `GET /api/v1/sector-fund-flow/timeseries`（handler 按 query `sector_names`+`sector_type` 返回对应曲线）
- `mockFundFlowTimeseriesError(page)` / `mockFundFlowTimeseriesEmpty(page)` — 错误/空态
- `mockFundFlowLatestDate(page, latestDate?)` — mock `GET /api/v1/sector-fund-flow/latest-date`
- `installFullFundFlowMocks(page)` — 一键安装全量默认 mock
- Test data factories：`createTestFundFlowRankings({sectorType})` / `createTestFundFlowTimeseries({sectorNames, sectorType})` / `createTestFundFlowLatestDate()`

### 源码 data-testid（已落地）

- `SectorFundFlowPage.tsx` → 视图切换 `fund-flow-view-ranking`/`fund-flow-view-chart`（`aria-selected`）；维度切换 `fund-flow-sector-type-{industry|concept|region}`（class 区分激活态，无 aria）；日期 `fund-flow-date-input`；刷新 `fund-flow-refresh`；已选区 `fund-flow-selected-sectors`；移除 `fund-flow-remove-sector-{name}`；候选 `fund-flow-toggle-sector-{name}`；引导态 `fund-flow-timeseries-guide`
- `FundFlowRankingTable.tsx` → 表格 `fund-flow-ranking-table`；排序按钮 `fund-flow-sort-{net_inflow|inflow|outflow}`；板块跳转 `fund-flow-sector-link-{sectorName}`；错误态 `fund-flow-ranking-error` + 重试 `fund-flow-ranking-retry`；空态 `fund-flow-ranking-empty`
- `FundFlowTimeseriesChart.tsx` → 容器 `fund-flow-timeseries-chart`；错误态 `fund-flow-timeseries-error` + 重试 `fund-flow-timeseries-retry`；空态 `fund-flow-timeseries-empty`

### 注意事项

- `sector-type` 按钮无 `aria-selected`/`aria-pressed`（与 fund-crowd 的 `crowd-sector-type-*` 不同），spec 用数据联动（首行板块名变化）佐证切换生效，不依赖 aria 断言。
- 视图切换按钮用 `aria-selected`（`role="tab"`），spec 可直接断言。
- 金额单位为元（后端原始），前端换算成亿/万展示（`formatSignedAmount`：12亿 → `+12.00亿`）。
