# E2E 测试用例：数据状态标签页

## 资产现状

- Playwright projects: admin（端口 3100，Next.js 开发服务器）
- 现有相关 spec: 无（首次 E2E 测试）
- 可复用 helpers: mock-api.ts（mockDataStatusNormal, mockDataStatusMixed, mockDataStatusFailed, mockDataStatusNoData, mockDataStatusError, mockBackfillSuccess, mockBackfillConflict, mockBackfillError）
- 可复用 fixtures: 无（首次 E2E 测试）

## plan-03：前端数据状态标签页

> 来源：架构文档 §范围 第3条"新增前端标签页'数据状态'：三张状态卡片 + 补齐按钮 + 进度展示"，§2.1 范围

### Edge

| # | 场景 | 类型 | 前置条件 | 步骤 | 断言 | 目标 spec |
|---|------|------|---------|------|------|-----------|
| TC-3.12 | 点击重试重新请求状态 API | Edge | mock 状态 API 返回 500；然后 mock 切换为正常数据 | 访问页面后点击"重试"按钮 | 错误态消失，三张状态卡片正常展示 | data-status.spec.ts |
| TC-3.13 | 点击重新补齐按钮再次创建任务 | Edge | mock 状态 API 返回 failed 任务；mock 补齐 API 返回成功 | 点击"重新补齐"按钮 | POST backfill API 被调用；按钮变为禁用态 | data-status.spec.ts |

### 需要新增的 mock / fixture

- `mockDataStatusNormal(page)` — mock GET /api/v1/admin/data/status 返回三类正常状态
- `mockDataStatusMixed(page)` — mock 返回混合状态（含缺失和活跃任务）
- `mockDataStatusFailed(page)` — mock 返回含失败任务的状态
- `mockDataStatusNoData(page)` — mock 返回 no_data 状态
- `mockDataStatusError(page)` — mock 返回 500 错误
- `mockBackfillSuccess(page, type)` — mock POST /api/v1/admin/data/backfill/{type} 返回成功
- `mockBackfillConflict(page, type)` — mock POST 返回 409
- `mockBackfillError(page, type)` — mock POST 返回 500

以上均已实现在 `web/tests/e2e/helpers/mock-api.ts`。
