### 需要新增的 mock helpers（`web/tests/e2e/helpers/mock-shareholder-analysis-api.ts`）

- `mockShareholderOverview(page, overview, responses?)` — mock `GET /api/v1/shareholder-analysis/overview`（支持多次调用返回不同报告期，用于 AC-09 切换场景）
- `mockShareholderOverviewEmpty(page)` — mock overview 返回空（`report_periods: []` / `groups: []`），用于 AC-08
- `mockShareholderSummary(page, summary, responses?)` — mock `GET /api/v1/shareholder-analysis/summary`（支持按 query 参数 industry/change_direction 返回不同数据）
- `mockShareholderIndustryDistribution(page, distribution, responses?)` — mock `GET /api/v1/shareholder-analysis/industry-distribution`
- `mockShareholderHoldings(page, holdings, total, responses?)` — mock `GET /api/v1/shareholder-analysis/holdings`（支持分页 + 行业/变动方向筛选）
- Test data factories：
  - `createTestOverview({ hasPrevPeriod?: boolean })` — 构造 5 组 + 默认 hasPrevPeriod=true 的概览
  - `createTestOverviewEmpty()` — 空概览
  - `createTestSummary({ hasPrevPeriod?: boolean })` — 单组汇总 + 趋势
  - `createTestIndustryDistribution()` — 含"银行/白酒/保险"等行业
  - `createTestHoldings({ filter?: { industry?, changeDirection? } })` — 国家队持仓 4 只，支持按 industry/change_direction 筛选返回子集
  - `createMultiGroupHoldings()` — 多组去重持仓 5 只（601398 在两组中重复匹配，去重后 5 只）

**注意**：4 个端点共用同一 query 参数（group_ids/report_period），mock handler 内需按 `URLSearchParams` 解析 `industry` / `change_direction` / `page` 决定返回哪份 fixture。所有 handler 在不匹配自己负责的方法/路径时调用 `route.fallback()`，避免 LIFO 短路（参照 mock-shareholder-api.ts 注释）。
