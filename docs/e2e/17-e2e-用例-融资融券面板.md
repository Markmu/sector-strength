## 降级与回归（spec 边界 / plan-07 §边界场景）

- L1（最近交易日未更新）：卡片展示最近成功结果及其日期（`margin-latest-date` = latest.tradeDate，非今天）
- 缺口（L2）：`connectNulls:false` 断线 + `margin-missing-hint`（TC-7.3 覆盖；断言 null 点未被 0/前值填充）
- 范围内点数 < N：如实渲染已有交易日点（factory 满数据按 range 生成，TC-7.2 间接覆盖不同点数）
- 快速连续切换范围：SWR key 去重，最后一次生效（TC-7.2 覆盖 90→250 序列）
- 相邻面板回归：16 期 `market-metrics-panel` spec 不受影响（plan-07 §6 验证命令 4）；错误重试仅重发 margin trend、不动 market-metrics 请求（TC-7.5 计数断言）
