## 契约（plan-07 §1 / plan-06 §7.2 同源）

```ts
MarketMetricPoint {
  tradeDate: string
  volumeShares: number | null   // 股
  amountYuan: number | null     // 元
  averagePrice: number | null   // 2 位小数
  finalStockCount: number | null
  suspendedStockCount: number | null
}
MarketMetricsTrendData {
  latest: MarketMetricPoint | null
  points: MarketMetricPoint[]
  range: 30 | 90 | 250
  hasMissingDates: boolean      // 任一点 volumeShares 为 null → true
}
MetricKey = 'amountYuan' | 'volumeShares' | 'averagePrice'
```

## 需要新增的 mock / fixture（本期在 helper 内生成，无独立 JSON fixture）

`web/tests/e2e/helpers/mock-market-metrics-api.ts`：

- `createTestMarketMetricsTrend(opts?)` — test data factory：`range` 控制点数；`empty=true` → latest=null/points=[]；`gaps=true` → 7 日轴中 2 日 null、hasMissingDates=true
- `mockMarketMetricsTrend(page, data?)` — GET `/api/v1/market-metrics/trend`，按 query `range` 返回满数据（默认）或传入 fixture
- `mockMarketMetricsTrendEmpty(page)` — 全空 fixture（latest=null）
- `mockMarketMetricsTrendGaps(page)` — 部分缺口 fixture（hasMissingDates=true）
- `mockMarketMetricsTrendError(page)` — 500

## 降级回归（架构 §8.2）

- L1（最新交易日未更新）：卡片展示「最近成功结果及其日期」（`market-metrics-latest-date` = latest.tradeDate，非今天）
- L2（趋势失败日 → null 断点）：`connectNulls:false` + `market-metrics-missing-hint`（TC-7.5 覆盖）
- 新增面板不遮挡/不错位两套既有布局（TC-7.1/7.2 DOM 顺序断言间接覆盖）
