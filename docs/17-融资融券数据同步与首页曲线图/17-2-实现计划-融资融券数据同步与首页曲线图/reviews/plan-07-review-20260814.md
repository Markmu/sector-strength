## 重点复核项（验收指示逐条）

### 1. 双 Y 轴右轴 rqye+rzmre（元口径，rqmcl 不入图）— 通过

- `SERIES_CONFIG`（MarginPanel.tsx:71-81）恰 4 条全 `type: 'line'`：rzye（axis 0）、rzrqye（axis 0）、rqye（axis 1）、rzmre（axis 1）；`rqmcl` 不在 series 也不在卡片，仅存于 `MarginPoint` 类型与 mock 契约（与「路径一致性说明」锁定口径一致）。
- 双轴均 `{ type: 'value', name: '亿元', scale: true }`（:163-180），右轴 splitLine 关闭避免双轴网格干扰。
- E2E TC-7.1 经 `__echartsInst__` 读 `getOption()` 断言：左轴 `yAxisIndex 0` = 融资余额+两融合计余额、右轴 `1` = 融券余额+融资买入额，本次重跑通过。

### 2. legend 4 项 — 通过

`legend.data = SERIES_CONFIG.map(s => s.label)` = [融资余额, 两融合计余额, 融券余额, 融资买入额]，恰 4 项；E2E `expect(chart.legend).toEqual(LEGEND_ITEMS)` 精确断言（非 contains）。

### 3. 卡片 ÷1e8 — 通过

- `formatBillion`（:84-87）= `(val / 1e8).toLocaleString('zh-CN', { maximumFractionDigits: 2 })`，与规格逐字一致。
- `CARD_CONFIG` 4 指标（rzye/rqye/rzrqye/rzmre）+ 最近结果日共 5 格 `grid grid-cols-2 sm:grid-cols-5`。

### 4. connectNulls:false — 通过
