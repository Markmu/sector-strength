## 重点复核项（任务要求逐条）

### 1. 零 Provider 调用（spec REQ-6 硬约束）— 通过

- **文件级（ast）**: `margin.py` import 区仅 `logging/time/datetime/decimal/fastapi/pydantic/sqlalchemy/src.api.deps/src.models/src.models.user`，无任何 Provider 侧模块（`trading_calendar` / `data_acquisition` / tushare）。测试 `test_margin_module_does_not_import_providers` 用 `ast.parse(inspect.getsource(...))` 断言 import 语句与符号双维度（banned_prefixes + banned_names），docstring 警示文字不作数 — 断言方式严密。
- **运行时（mock）**: `test_get_path_never_touches_providers` 同时 mock `DataSourceFactory.create` / `TradingCalendar` / `TushareDataSource` 并断言 `assert_not_called()`（含类实例化即失败），请求全程 200。
- **代码审查佐证**: 读路径只查 `trading_calendar_days` + `market_margin_daily` 两张本地表，无 Provider 实例化点。

### 2. 缺口映射 null 非 0 — 通过

- `_to_point(cal, None)` 返回六指标全 `None`（margin.py:85-94），无 0/前值填充分支。
- `test_gap_points_are_null`：5 日轴 + 3 日数据 → 5 点、后 2 点六指标逐项断言 `is None`、`tradeDate` 锚点仍在、`hasMissingDates=true`、`latest` 为第 3 日（非轴上最后一日）。
- `test_all_metrics_missing`：日历有开市日但两融全空 → `latest=null`、`hasMissingDates=true`。

### 3. camelCase + Decimal→float — 通过

- helper `_serialize_value`（Decimal→float、date/datetime→isoformat）与 `_dict_to_camel`（递归 snake→camel）复制自 index_monitor.py 同源；端点返回 `{"success": True, "data": _dict_to_camel({...})}`。
- `test_full_data_contract` 断言：`set(data.keys()) == {latest, points, range, hasMissingDates}`；point 恰为七键 `tradeDate/rzye/rqye/rzmre/rzche/rqmcl/rzrqye`（`rqyl` 不输出，spec D1/plan-01 口径）；六指标 `isinstance(x, float)`；`date.fromisoformat(tradeDate)` 合法；rzye=1.8e12 原始元口径（不 ÷1e8，转亿留给 plan-07）。

### 4. range 校验 30/90/250 与非法 422 — 通过

- 签名 `range: str = Query("30", pattern="^(30|90|250)$")` + 端点内 `int()`（16 期 Pydantic 2.12 pattern-on-int 实测教训照搬，注释完整）。
- `test_range_30_90_250_cropping`：100 开市日 → 30/90/250 分别返回 30/90/100 点，尾部对齐最后一日；`test_range_exceeds_available_open_days`：仅 3 开市日返回全部 3 点。
- `test_invalid_range_rejected_422`（50）与 `test_non_numeric_range_rejected_422`（abc）均 422。真机无 token 访问 `range=50` 亦被鉴权优先拦为 401（FastAPI 依赖先于 query 校验，安全语义正确）。

### 5. 鉴权（401 / 普通用户可读）— 通过

- `Depends(get_current_user)`；`test_requires_authentication` 裸 client 无 token → 401；`test_normal_user_can_read` 注入 `role="user"` 普通用户 → 200。
- 真机探测（本机 8000 端口运行中服务）：`GET /api/v1/margin/trend?range=30` 无 token → `401 {"detail":"Not authenticated"}`，端点已挂载且鉴权生效。

### 6. 实现规格其余条款 — 通过

- 日历轴：`is_open=True` DESC LIMIT N → `reverse()` 升序（margin.py:142-149）；空表 → HTTP 200 + `success=False` + "交易日历未初始化，请先执行融资融券同步" + `data=null`（不伪造自然日）。
- LEFT JOIN：`outerjoin(MarketMarginDaily, trade_date == cal_date)` + 参数化 `in_(dates)` + 升序，`metric_map` 过滤 None。
- `latest`：points 自尾向头第一个 `rzye` 有值点；全空 → null。`hasMissingDates`：任一点 `rzye is None`。判据取 `rzye` 为交接上下文声明的"16 期取 volume_shares 同位裁定"，非新造 AC。
- 可观测性：`margin trend: range/points/missing_count/db_duration_ms` info 日志（margin.py:195-201）。
- 挂载链核对：v1 主路由 `/v1` + main `/api` + prefix `/margin` = `/api/v1/margin/trend`，测试与真机均实际命中。
