# 06-0 需求设计：股东分析面板

## 0. 文档说明

**产品核心目标**：让投资者能追踪重点机构（国家队、外资、社保等）的持仓动向，快速发现"聪明钱在买什么"。

**本需求定位**：
- **上期基础**：05 期已完成全市场股票十大流通股东数据的同步与入库，管理后台可触发同步任务。
- **本期做什么**：新增面向用户的"股东分析面板"页面，对股东进行分组标签管理（预定义 + 后台可编辑），按监控组展示持仓汇总和变动趋势，支持按监控组查询持仓股票及其行业板块分类。
- **阶段定位**：数据消费层建设。将 05 期积累的股东数据转化为用户可感知的分析能力。

**相关文档**：
- 05 需求设计：股票十大流通股东同步
- 04 需求设计：A 股基金持仓分析

## 第一部分 需求分析与确认

### 1.1 项目背景

十大流通股东数据已通过 05 期完成入库，但数据"沉睡"在数据库中，用户无法感知。典型场景：投资者想知道"社保基金最近一季在买什么、卖什么"，目前无法回答。

更关键的是，十大流通股东名单中鱼龙混杂——既有高盛、摩根士丹利等顶级外资投行，也有不知名的个人股东。用户真正关心的是特定类别机构的集体行为：国家队整体在加仓还是减仓？外资投行最近看好哪些行业？目前数据缺少身份识别和分组聚合能力。

**具体问题**：

1. **股东数据不可见**：十大流通股东数据已入库，但站内无任何面向用户的展示入口，用户无法查询。
2. **股东身份无法识别**：同名股东在不同报告中名称可能有微小差异（"全国社保基金一一六组合" vs "全国社保基金116组合"），缺乏统一的身份识别和标签体系。
3. **缺少机构持仓汇总视角**：用户无法看到"国家队""外资""社保"等关键机构的整体持仓分布和变动趋势，只能逐只股票逐一查看股东名单。
4. **缺少行业维度分析**：用户无法了解重点监控组持仓股票集中在哪些行业，无法发现机构的行业偏好。

**本期目标（一句话）**：让用户能按"国家队""外资"等监控组维度查看机构持仓汇总和变动趋势，按组查询持仓股票并按行业分类筛选。

### 1.2 核心问题定义

| 问题 | 用户损失 |
|---|---|
| 十大流通股东数据不可见 | 用户无法获知个股的主力持仓结构，信息断层 |
| 股东无分组标签 | 用户无法区分"国家队"和"散户"，无法追踪机构集体行为 |
| 无持仓汇总视角 | 只能逐只股票看股东名单，无法了解一个机构组的整体持仓分布 |
| 无变动趋势统计 | 不知道重点机构在增持还是减持，无法判断"聪明钱"动向 |
| 无行业维度 | 无法发现机构的行业偏好，错过行业轮动信号 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
|---|---|---|---|
| 分组来源 | 预定义核心分组 + 后台可增删改 | 兼顾开箱即用和灵活扩展 | 完全硬编码（不灵活）、完全自定义（首版过重） |
| 股东匹配方式 | 按股东名称关键词匹配 | 十大流通股东数据的唯一识别依据是名称，关键词匹配实现简单且覆盖主流场景 | 精确名称匹配（同名变体无法匹配）、独立股东实体表（首版过重） |
| 统计维度 | 持仓汇总 + 变动趋势两者 | 用户既需要"当前持有什么"也需要"最近在变化什么"，缺一不可 | 仅汇总（看不到趋势）、仅趋势（不知道现状） |
| 变动判定 | 与上一报告期对比持股数量变化 | 自然季度间隔适合观察机构调仓节奏，数据源按季度披露 | 按月对比（数据源不支持月度） |
| 页面定位 | 面板页，监控组概览 + 下钻查询 | 与基金持仓分析页平级，聚焦"机构视角"而非"个股视角" | 嵌入个股详情页（缺少机构聚合视角） |
| 行业维度数据来源 | 使用板块表（sectors）中 type=industry 的行业板块，通过 sector_stocks 关联 | 行业板块数据已在板块体系中维护，结构化程度高，且与站内其他板块分析页面一致 | 使用 Stock.industry 文本字段（非结构化，可能存在不一致） |

### 1.4 产品范围

**本期范围（必须交付）**：

- **股东分组标签体系**：预定义核心监控组（国家队、社保、外资投行、保险公司等），每组包含成员匹配规则（按股东名称关键词），后台管理员可增删改分组和成员规则。
- **股东分析面板页**：面向用户的独立页面，展示各监控组的持仓汇总统计和变动趋势统计。
- **监控组持仓查询**：支持选择一个或多个监控组，查询该组所有成员当前报告期的持仓股票列表。
- **行业分类筛选**：对监控组持仓股票按行业进行分组统计和筛选。

**明确不做**：

- 个股维度的十大流通股东详情页（本期聚焦机构聚合视角）
- 股东跨多个报告期的详细持仓时间线
- 股东关联关系分析（如同一控制人下的多个账户）
- 自定义监控组创建（用户侧，本期仅管理员后台管理）
- 持仓变动预警通知
- 个股详情页跳转（前端尚无股票详情页路由，本期不做跳转，后续可新增）

## 第二部分 用户旅程和用户故事

### 2.1 核心用户旅程

**主旅程：用户查看监控组持仓分析**

```
[1. 用户从导航栏进入"股东分析"页面]
   ↓
[2. 页面顶部展示监控组概览卡片：国家队（持仓 128 只）、外资投行（持仓 256 只）、社保（持仓 89 只）...]
   ↓
[3. 用户点击"国家队"卡片（或选择多个组）]
   ↓
[4. 下方展示该组持仓汇总：总持股数量、总持股市值估算、占流通股比例均值]
   ↓
[5. 展示行业分布：按行业统计持仓股票数量占比（如银行 32%、保险 18%），可视化展示各行业分布]
   ↓
[6. 展示变动趋势：相对上期增持 X 只、减持 Y 只、新进 Z 只、退出 W 只]
   ↓
[7. 下方表格列出该组持仓的所有股票：股票代码、名称、持股数量、占流通股比例、较上期变动、行业]
   ↓
[8. 用户在筛选栏选择行业"银行"，表格实时过滤]
```

**异常旅程**：

- **数据未同步**：若十大流通股东数据尚未同步过（05 期任务未执行），页面展示空状态提示"暂无股东数据，请联系管理员同步数据"。
- **报告期数据缺失**：若当前报告期或上期数据不完整，变动趋势部分展示"数据不完整"标记，汇总统计基于可用数据计算。

**管理旅程：管理员管理监控组**

```
[1. 管理员进入"管理后台 → 股东分组管理"]
   ↓
[2. 查看当前所有监控组：组名、成员数量、匹配规则]
   ↓
[3. 编辑"国家队"分组：新增匹配关键词"中央汇金"、删除过时关键词]
   ↓
[4. 新增监控组"QFII"：输入组名、描述、添加匹配关键词]
   ↓
[5. 保存，页面刷新后新分组在用户侧面板可见]
```

### 2.2 用户故事

**核心用户故事**：

- **US-01**：作为投资者，我希望在"股东分析"页面看到各监控组（国家队、外资、社保等）的概览卡片，每组显示持仓股票数量和核心统计数据，以便快速了解机构持仓全景。
- **US-02**：作为投资者，我希望点击某个监控组后查看该组的持仓汇总（总持股数、占流通股比例等）、行业分布（各行业持仓占比）和变动趋势（增持/减持/新进/退出数量），以便判断该组机构的整体动向和行业偏好。
- **US-03**：作为投资者，我希望查看某个监控组持仓的所有股票明细列表（含持股数量、变动方向、行业），以便发现具体标的。
- **US-04**：作为投资者，我希望对监控组的持仓股票按行业进行筛选，以便发现机构的行业偏好。

**延伸用户故事**：

- **US-05**：作为管理员，我希望在后台管理监控组（增删改组名、描述、匹配规则），以便灵活调整分组策略而无需改代码。
- **US-06**：作为投资者，我希望同时选择多个监控组进行对比查看，以便了解不同机构群体的持仓差异。
- **US-07**：作为投资者，我希望在持仓股票列表中按持股变动方向（增持/减持/新进/退出）筛选，以便聚焦特定动向的股票。

### 3.3 业务规则

- **报告期选择**：下拉框展示最近 4 个季度的报告期（如 2025-03-31、2024-12-31 …），默认选中最近一个有数据的报告期。变动趋势与上一个报告期对比。
- **监控组卡片排序**：按持仓股票数量降序排列。
- **股东匹配规则**：每个监控组包含一组"股东名称包含"关键词，只要股东名称包含任一关键词即归入该组。一个股东可同时匹配多个组。
- **变动方向判定**：通过跨报告期对比自行计算（不依赖 Tushare 的 hold_change 字段，因该字段无法覆盖新进/退出场景）：
  - **新进**：当前报告期出现但上期未出现
  - **退出**：上期出现但当前报告期未出现
  - **增持**：两期都有，当前持股数量大于上期
  - **减持**：两期都有，当前持股数量小于上期
  - **不变**：两期都有，持股数量相同
- **汇总统计**：
  - 持仓股票数 = 当前报告期该组匹配到的去重股票数
  - 总持股数 = 该组所有持股记录的持股数量之和
  - 平均占流通股比例 = 该组所有持股记录的占流通股比例均值
- **行业分布**：按行业统计该组持仓股票数量占比，以水平条形图展示，按占比降序排列，展示前 N 个行业并合并其余为"其他"。用户点击某个行业条目等同于在筛选栏选中该行业，股票列表联动过滤。
- **行业来源**：取自板块表（sectors）中 type=industry 的行业板块，通过 sector_stocks 关联表获取每只股票所属行业。一只股票可能属于多个行业板块，全部展示（持仓列表中逗号分隔，行业分布中按独立计数统计）。
- **分组管理权限**：仅管理员可操作监控组的增删改。分组变更后实时生效（下次查询使用新规则匹配）。
- **分页**：持仓股票列表默认每页 20 条，支持翻页。

## 第四部分 验收标准

- **AC-01：监控组概览展示**
  前置：十大流通股东数据已同步至少一个报告期，且存在预定义的监控组。
  动作：用户进入"股东分析"页面。
