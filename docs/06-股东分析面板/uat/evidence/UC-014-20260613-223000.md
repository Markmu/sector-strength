# UAT 失败证据：UC-014 行业分布图数据为空

**Case ID:** UC-014
**用例标题:** 行业分布图点击联动筛选
**执行日期:** 2026-06-13 22:30
**执行人:** MUCHAO
**执行状态:** Failed

## 失败摘要

行业分布 API `get_industry_distribution` 在真实数据（国家队 403 只股票）下返回 **空 `distribution=[]`**，导致 plan-04 前端行业分布条形图无数据可渲染（显示"暂无行业分布数据"）。自动化测试（plan-02 pytest）未暴露此问题，因其 fixture 仅 6 只股票、3 个行业，占比足够高。

## 根因分析

代码位置：`server/src/services/shareholder_analysis_service.py:688-706`

```python
for ind, cnt in industry_counter.items():
    pct = (cnt / total_count * 100) if total_count else 0.0
    if ind == _UNDEFINED_INDUSTRY:
        others_count += cnt          # 仅"未定义行业"归入其他
    elif pct >= _INDUSTRY_MIN_PERCENTAGE:   # 5% 阈值
        items.append({...})           # 只有 >=5% 才展示
    # ← pct<5% 的"有名字行业"既不展示，也不合并到"其他"，被直接丢弃
```

三因素叠加导致空结果：
1. **多行业摊薄**：一只股票属多个行业（如 000001 有 6 个行业），`total_count` 按行业计数膨胀（403 股 → 2418 行业计数）。
2. **5% 阈值**：真实数据行业极度分散（419 个不同行业），最高占比仅 3.6%，无一 ≥5%。
3. **低占比未合并**：pct<5% 的有名字行业没有归入"其他/未分类"（others 只收 `_UNDEFINED_INDUSTRY`），被丢弃。

`_INDUSTRY_MIN_PERCENTAGE = 5.0`。

## 影响

- plan-04 前端 `IndustryDistribution` 组件无数据，行业分布条形图恒为空状态。
- AC-02 "行业分布（各行业持仓占比可视化展示）"在真实数据下不满足。
- UC-004 行业筛选本身正常（holdings industry 参数可用），仅分布图聚合层有问题。

## 修复建议

将 pct < 阈值的**有名字行业**也合并到"其他/未分类"，符合 plan-02 §3.4"前 N 个行业（占比 > 5%）独立展示，**其余合并为'其他/未分类'**"：

```python
for ind, cnt in industry_counter.items():
    pct = (cnt / total_count * 100) if total_count else 0.0
    if ind == _UNDEFINED_INDUSTRY or pct < _INDUSTRY_MIN_PERCENTAGE:
        others_count += cnt      # 未定义 + 低占比 都合并到"其他"
    else:
        items.append({"industry": ind, "stock_count": cnt, "percentage": pct})
```

补充：可考虑调整阈值（如 3%）或按"股票数占比"而非"行业计数占比"计算，使分布图更有区分度。需同步补一个多行业摊薄场景的 pytest 用例。
