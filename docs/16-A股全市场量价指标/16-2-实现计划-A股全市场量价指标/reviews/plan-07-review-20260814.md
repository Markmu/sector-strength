## 3. 实现偏差特别裁定（3 处，全部接受）

### 偏差 a：SWR `dedupingInterval: 0`（锚点 IndexMonitorPage 为 30000）

- **位置**: `web/src/components/market-metrics/MarketMetricsPanel.tsx` L46-49（含注释说明）。
- **规格原文**: §3 "SWR 范式（照抄 IndexMonitorPage.tsx:38-52）"——字面照抄会带 30000 去重。
- **裁定依据**:
  1. **plan-07 §8 边界表自身已声明该行为**："快速连续切换范围 → SWR key 去重，最后一次生效（**dedupingInterval:0 保证显式切换重拉**）"——属计划内约定，非未申报偏离。
  2. **AC-05 的 E2E 断言硬性要求**：TC-7.4 在数秒内 30→90→250→**切回 30** 并 `waitForRequest(range=30)`。若沿用 30000，切回 30 时初始加载的 range=30 请求仍在去重窗口内 → 不重发 → 用例超时失败。review 重跑确认当前实现下 8/8 通过。
  3. 副作用可控：`revalidateOnFocus: false`，仅用户显式切换才重拉；重拉期间 SWR 仍先展示该 key 缓存数据，无 UI 闪断。
- **结论**: **接受**。偏离有据（计划内 + AC 硬约束），不构成 blocker。

### 偏差 b：普通分支面板 `!isLoading` 门控

- **位置**: `web/src/app/dashboard/page.tsx` L69 `{!isLoading && <MarketMetricsPanel />}`。
- **规格原文**: §3-4 只约定插入位置（快捷入口后、市场强度前），未要求门控。
- **裁定依据**:
  1. **竞态真实存在**：`AuthContext` 首帧 `user=null` → `isAdmin=false`，管理员加载时 /dashboard 短暂渲染普通分支（E2E red 证据"宿主页稳定"一节亦实录了这一竞态）。无门控时面板会在过渡帧挂载：多发一次 trend 请求、以 `isAdmin=false` 身份闪现空态（无管理员链接）后卸载。
  2. **行为不变性**：`AuthContext.isLoading` 在初始化 effect 的 `finally` 中必然置 false（AuthContext.tsx L144-146），普通用户最终必然渲染面板；插入位置不变。AC-04 E2E（TC-7.2）在门控存在下通过。
  3. 代码内注释（L66-68）已记录原因。
- **结论**: **接受**。属竞态加固，验收标准未受损，不构成 blocker。

### 偏差 c：spec helper `expectPanelRelativeToHeading` 测试 bug 修复

- **位置**: `web/tests/e2e/market-metrics-panel.spec.ts` L86-139（L97-99 注释自述修复）。
- **问题**: red 版 `page.evaluate` 在计算 `beforeOk` 后提前 return，同时传 `before+after` 时 `afterOk` 恒为 `undefined` → TC-7.2 的 after 断言对任何实现都会失败。
- **裁定依据**:
  1. **断言意图未变**：修复版保留 `rel.found==='ok'` 前置断言与 `no-before-target`/`no-after-target` 快速失败守卫；`compareDocumentPosition` 的 FOLLOWING/PRECEDING 语义与原意一致（panel 在目标前 / 后）。
  2. **断言变强而非放宽**：red 阶段 8 个失败全部止于首个断言（`market-metrics-panel` not found），helper bug 未影响 red 结论"预期失败，测试有效"；修复后 TC-7.2 的 after 断言**真正执行并通过**，比带 bug 版本更严格。
  3. 影响 scope：仅 TC-7.2 同时使用 before+after（TC-7.1 只用 before），修复不涉及其余 7 例。
- **结论**: **接受**。属测试基建修复，red 有效性、green 严格性均成立。
- **附带备注（非阻塞）**: green 证据"spec 是否变更：否（同一 spec 文件，断言未放宽）"中"断言未放宽"属实，但"未变更"表述未涵盖 helper 代码修复；本报告已裁定，无需回改证据文件。
