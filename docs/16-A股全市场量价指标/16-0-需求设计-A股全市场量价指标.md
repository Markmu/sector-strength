# 16-0 需求设计：A股全市场量价指标

## 0. 文档说明

**产品核心目标**：让用户在首页快速判断 A 股全市场的流动性变化与整体价格水平，并为管理员提供可回填、可追踪的日度数据同步能力。

**本需求定位**：基于现有 A 股日行情采集、后台数据同步和首页市场监控能力 + 新增全市场成交量、成交额与平均股价的日度计算和保存 + 在首页形成连续趋势图，定位为盘后市场研判的基础量价指标。

**相关文档**：
- 第 01 期《自动数据质检与每日拉取补全》：既有交易日判断与每日更新链路
- 第 02 期《数据状态总览与一键补齐》：既有数据管理与补齐任务体验
- 第 03 期《数据源替换》：既有 A 股全市场日行情来源
- 第 15 期《关键指数监控面板》：现有管理员首页市场研判模块

## 第一部分：需求分析与确认

### 1.1 项目背景

**产品当前状态**：平台根据用户角色展示两套首页，管理员首页侧重关键指数行情、走势、估值和成分权重，普通用户首页侧重市场强度、板块热力图和排名；两套首页都尚未提供能够代表全市场交易活跃度与整体价格水平的连续指标。

**存在的问题：**

1. **缺少全市场成交额趋势**：用户只能看到单个指数的成交数据，无法直接判断整个 A 股市场当天是放量还是缩量。
2. **缺少全市场成交量趋势**：当前首页无法呈现实际成交股数的变化，用户难以区分成交额变化来自交易活跃度还是股价水平变化。
3. **缺少全市场平均股价**：指数点位受编制规则和权重股影响，不能直接回答全市场股票的平均价格水平如何变化。
4. **历史指标不可回填**：管理员没有独立入口按日期范围生成这些指标，首页无法获得连续的历史曲线。
5. **日常更新未形成闭环**：即使基础行情已经更新，仍缺少将每日全市场行情汇总为市场指标并持续保存的任务。

**本期目标**：每个交易日基于当日全部沪深北 A 股行情生成全市场成交量、成交额和平均股价；用户可在首页查看趋势，管理员可在数据管理页按日期范围同步和修复历史数据。

### 1.2 核心问题定义

| 问题 | 用户损失 |
|------|---------|
| 首页只有指数行情，没有全市场量能 | 无法快速判断市场整体放量或缩量，盘后复盘仍需依赖外部行情工具 |
| 成交额、成交量与价格水平相互割裂 | 无法区分资金规模、交易活跃度和股价水平分别发生了什么变化 |
| 市场平均价格缺失 | 用户只能通过加权指数感知行情，缺少不按市值加权的横截面价格观察值 |
| 历史数据不能按时间同步 | 历史曲线出现缺口后无法自助修复，影响趋势判断 |
| 指标缺少稳定的日度保存 | 首页每次都重新依赖大批明细行情，难以保证展示速度和历史口径一致 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
|---------|---------|---------|---------|
| 指标生成方式 | 按交易日读取全市场当日行情，计算后保存日度结果 | 一次计算即可得到统一、可复核的三项指标，也便于历史回填 | 每次打开首页临时汇总（慢且历史口径容易变化） |
| 市场范围 | 沪市、深市、北市全部 A 股 | 与“全市场”认知一致，北交所不可被遗漏 | 只统计沪深两市（市场范围不完整） |
| 行情完整性 | 目标交易日所有已上市且未退市的 A 股均参与计算；全天停牌股票按停牌规则补齐 | “全市场”必须覆盖完整股票集合，不能因停牌或行情遗漏悄然缩小范围 | 只统计有当日行情的股票（会遗漏全天停牌股票） |
| 平均股价口径 | 所有参与计算股票有效收盘价的简单算术平均 | 提供不按市值加权的横截面价格观察值，口径直观且可复核 | 市值加权平均（与宽基指数含义接近） |
| 首页呈现 | 三项最新值 + 单指标趋势图 + 时间范围切换 | 三项指标单位不同，按指标切换比多纵轴叠加更易读 | 三条曲线同图叠加（单位不同，容易误读） |
| 默认指标 | 成交额 | 成交额是盘后判断市场放量、缩量最常用的总量指标 | 默认平均股价（不如成交额直接反映市场活跃度） |
| 同步入口 | 数据管理页新增“市场量价”分类 | 与其他数据同步能力集中管理，管理员路径一致 | 首页直接提供同步按钮（普通用户不应操作数据任务） |
| 更新方式 | 交易日收盘后自动生成当日指标，同时支持管理员按日期范围手动同步 | 自动更新保证首页时效，手动同步用于初始化和修复缺口 | 仅手动同步（容易遗漏最新数据） |
| 首页落位 | 管理员首页放在关键指数总览之前；普通用户首页放在快捷入口之后、市场强度之前 | 两类用户都能优先看到同一市场量价信号，同时不改变各自既有分析模块 | 只在一套首页展示（与全用户可见目标冲突） |
| 可见范围 | 两套首页的图表均对对应登录用户可见；同步管理仅管理员可见 | 市场量价属于通用研判信息，数据操作仍需权限隔离 | 图表仅管理员可见（普通用户失去基础市场信号） |

### 1.4 产品范围

**本期交付：**

1. **日度市场量价指标**：按交易日核对当日应参与的完整股票集合，生成并保存全市场成交量、成交额、平均股价和参与计算的股票数量。
2. **自动更新**：交易日收盘后，在全市场当日行情可用时自动生成当日指标。
3. **按时间同步**：管理员可选择开始日期和结束日期，按交易日批量同步所选范围内的指标。
4. **同步过程管理**：展示任务进度、成功和失败日期、完成结果及历史同步记录；相同日期可重新同步。
5. **首页趋势图**：管理员和普通用户首页均展示三项指标的最新值，支持在成交额、成交量、平均股价之间切换，并查看最近 30、90、250 个交易日趋势。
6. **数据状态反馈**：覆盖加载中、无数据、部分日期缺失、加载失败和重新同步后的恢复状态。

**明确不做：**

- 盘中实时刷新或分钟级市场量价曲线
- 沪市、深市、北市分别展示的子市场对比
- 市值加权平均股价、等权价格指数或涨跌家数指标
- 行业、板块维度的成交量和成交额聚合
- 量价异常提醒、阈值告警和交易信号推荐
- 改变既有指数监控、市场强度、板块热力图或排名的内容与功能；新图表插入后这些模块顺序后移

## 第二部分：用户旅程和用户故事

### 2.1 核心用户旅程

**目标用户**：盘后查看市场整体流动性和价格变化的 A 股投资者，以及负责维护数据完整性的管理员。

```text
用户登录并进入与角色对应的首页
  ↓
在市场总览区域看到「全市场量价趋势」
  ├─ 查看最新交易日的成交额、成交量、平均股价
  ├─ 默认查看最近 30 个交易日的成交额趋势
  ├─ 切换到成交量或平均股价
  └─ 切换 30 / 90 / 250 个交易日范围观察中短期变化
  ↓
结合当前角色首页可见的其他市场数据完成盘后研判
  ├─ 管理员：继续查看关键指数行情、估值和成分结构
  └─ 普通用户：继续查看市场强度、板块热力图和排名

管理员需要初始化或修复历史数据时
  ↓
进入数据管理页的「市场量价」分类
  ↓
选择开始日期和结束日期
  ↓
启动同步任务
  ├─ 系统仅处理范围内的交易日
  ├─ 页面展示当前进度和正在处理的日期
  └─ 完成后展示成功日期数、跳过日期数和失败日期
  ↓
返回首页，查看更新后的趋势图

异常旅程：
  ├─ 所选范围无交易日 → 不创建任务，提示调整日期
  ├─ 某个交易日行情为空、存在股票遗漏或重复 → 不保存结果，记录该日期失败原因
  ├─ 部分日期同步失败 → 已成功日期保留，管理员可重新同步同一范围
  └─ 首页尚无指标数据 → 展示暂无数据；管理员可看到前往数据管理的引导
```

### 2.2 用户故事

**核心用户故事：**

- US-01：作为 A 股投资者，我希望在首页看到全市场每日成交额趋势，以便快速判断市场是在放量还是缩量。
- US-02：作为 A 股投资者，我希望在成交量、成交额和平均股价之间切换，以便区分交易活跃度、资金规模与价格水平的变化。
- US-03：作为 A 股投资者，我希望查看不同时间范围的量价趋势，以便同时完成短期复盘和中期比较。
- US-04：作为管理员，我希望按日期范围同步全市场量价指标，以便完成首次初始化或修复历史缺口。
- US-05：作为管理员，我希望看到同步进度、结果和失败日期，以便确认数据是否完整并针对失败日期重试。

**延伸用户故事：**

- US-06：作为用户，我希望图表明确标注最新数据日期，以便避免把旧数据误认为当日数据。
- US-07：作为管理员，我希望重复同步同一日期不会产生重复结果，以便安全修复已存在的数据。
- US-08：作为用户，我希望某些日期缺失时图表保留缺口而不是自动连线，以便知道历史数据不完整。

### 3.2 关键状态

| 状态 | 页面表现 | 用户下一步 |
|------|---------|-----------|
| 首页加载中 | 最新值与图表区域显示加载占位 | 等待数据返回 |
| 首页正常 | 展示三项最新值、最新交易日和默认 30 日成交额趋势 | 切换指标或时间范围 |
| 首页无数据 | 显示“暂无市场量价数据”；管理员额外看到数据管理入口 | 管理员前往同步，普通用户等待数据更新 |
| 历史日期缺失 | 趋势在缺失日期处断开，并提示“部分日期暂无数据” | 管理员按缺失范围重新同步 |

| 日期输入无效 | 在对应日期旁说明问题，不创建同步任务 | 修正日期 |
| 所选范围无交易日 | 提示“所选范围内没有交易日”，不创建同步任务 | 调整日期范围 |
| 无管理员权限 | 不展示同步管理入口；直接访问时提示无权限 | 返回首页 |
| 已有同步任务运行 | “开始同步”不可用，并展示当前任务进度 | 等待当前任务完成 |

### 3.3 业务规则

**市场范围与计算规则：**

- 全市场范围为上海证券交易所、深圳证券交易所、北京证券交易所的 A 股股票，不包含 B 股、基金、债券、指数等其他证券。
- 参与集合为目标交易日已经上市且尚未退市的全部 A 股；目标交易日尚未上市或已经退市的股票不属于该日参与集合。
- 正常交易或盘中临时停牌但仍有当日日行情的股票，使用唯一有效的当日收盘价、成交量和成交额参与计算。
- 经确认全天停牌且没有当日日行情的股票仍须参与计算：收盘价采用停牌前最近一个交易日的有效收盘价，成交量和成交额按 0 计入；页面和同步结果单独展示全天停牌股票数量。
- 完整性核对以该日参与集合为基准：每只股票必须恰好匹配一条有效当日日行情，或被确认为全天停牌并取得最近有效收盘价；任一股票无法匹配、行情重复、缺少可沿用收盘价，或任一交易所整体缺失，均视为当日行情不完整。
- 只有完整性核对通过后才计算和保存结果；同步结果同时展示应参与股票数、当日日行情股票数、全天停牌股票数和最终参与股票数。最终参与股票数必须等于应参与股票数。
- 全市场成交量为参与计算股票当日成交量之和，页面统一展示为“亿股”。
- 全市场成交额为参与计算股票当日成交额之和，页面统一展示为“亿元”。
- 全市场平均股价为全部参与计算股票有效收盘价的简单算术平均，即收盘价总和除以参与股票数；页面展示为“元”，保留两位小数。该指标只表达当日股票收盘价的横截面算术平均，不代表中位数、典型股票或市值加权市场表现。
- 三项指标均来源于同一批当日行情；每个交易日同时记录参与计算的股票数量，便于确认统计范围。
- 成交量和成交额采用每日行情中的统一主口径，不额外叠加仅在部分历史区间提供的盘后补充项，避免前后历史口径不一致。
- 当日全市场行情为空或关键数据无法完成计算时，不得把该日保存为 0，应将该日期标记为同步失败。

**按时间同步规则：**

- 开始日期和结束日期均为必填，起止日期包含在同步范围内。
- 开始日期不得晚于结束日期，结束日期不得晚于当前日期。
- 系统只处理所选范围内的交易日，周末和休市日自动跳过且不视为失败。
- 同一日期重新同步时，以本次重新计算的完整结果替换原结果，不产生重复日期。
- 日期范围内所有交易日成功后，任务状态为成功；如有日期失败，任务展示失败日期和原因，已成功日期继续保留。
- 同一时间只允许一个市场量价同步任务执行，进行中时禁止重复创建。
- 自动更新与手动同步遵循相同的市场范围和计算口径。

**首页图表规则：**

- 默认选择成交额和最近 30 个交易日；用户可切换成交量、平均股价及 90、250 个交易日范围。
- 最新值取系统已有数据中的最近交易日，并明确显示对应日期。
- 成交额和成交量使用适合比较规模的柱状图；平均股价使用适合观察连续变化的折线图。

- 缺失交易日不使用前值填补，也不跨缺口连接趋势。
- 用户切换指标或时间范围时保留当前页面位置，不刷新整个首页。

**权限规则：**

- 所有已登录用户均可查看首页图表。
- 管理员首页在关键指数总览之前展示；普通用户首页在快捷入口之后、市场强度之前展示。

## 第四部分：验收标准

- AC-01：完整行情生成单日全市场量价指标
  前置：某交易日应参与计算的股票为 A、B、C 三只，三只股票均有唯一有效行情；收盘价分别为 10、20、30 元，成交量分别为 100、200、300 股，成交额分别为 1,000、4,000、9,000 元
  动作：系统执行该交易日的市场量价同步
  结果：完整性核对显示应参与 3 只、实际参与 3 只；生成且仅生成一条该交易日结果，参与股票数为 3，成交量为 600 股，成交额为 14,000 元，简单平均股价为 20.00 元

- AC-02：按日期范围同步
  前置：管理员进入数据管理页的“市场量价”分类，所选范围内包含多个交易日和休市日
  动作：管理员选择开始日期和结束日期并启动同步
  结果：系统只处理范围内的交易日，页面持续展示处理进度和当前日期；完成后展示成功、跳过和失败日期数，并产生可查询的同步记录

- AC-03：重复同步安全覆盖
  前置：所选日期范围已经存在市场量价结果
  动作：管理员再次同步相同日期范围
  结果：对应交易日结果按最新当日行情重新计算，页面和同步记录均更新，任何交易日都不出现重复结果

- AC-04：首页展示与指标切换
  前置：系统已有不少于 30 个交易日的市场量价结果
  动作：管理员和普通用户分别进入各自首页，并依次切换成交额、成交量和平均股价
  结果：两套首页均显示三项最新值及最新数据日期；管理员首页图表位于关键指数总览之前，普通用户首页图表位于快捷入口之后、市场强度之前；趋势图随选择正确切换，成交额和成交量显示柱状趋势，平均股价显示折线趋势，数值单位正确

- AC-05：首页时间范围切换
  前置：首页已有不少于 250 个交易日的数据
  动作：用户依次选择最近 30、90、250 个交易日
  结果：图表按所选范围展示相应数量的交易日数据，当前指标选择保持不变，悬停可查看每个交易日的完整数值

- AC-06：无数据与缺失日期呈现
  前置：场景一为系统尚无市场量价结果；场景二为所选历史范围存在日期缺失
  动作：用户打开首页图表
  结果：场景一显示明确的无数据状态且管理员可前往数据管理；场景二在缺失处保留断点并提示部分日期暂无数据，不以 0 或前值替代

- AC-07：同步失败与恢复
  前置：日期范围内某交易日应参与 3 只股票，其中 1 只既没有当日日行情，也未被确认为全天停牌，或同一股票出现重复行情
  动作：同步任务执行到该日期，随后管理员在数据恢复后重新同步相同范围
  结果：首次完整性核对显示最终参与数与应参与数不一致或存在重复，不保存该日期结果，明确显示失败日期、缺失或重复原因，其他成功日期保留；重新同步时完整性核对通过，该日期生成正常结果，首页趋势恢复完整

- AC-08：自动更新最新交易日
  前置：当日为交易日且收盘后的全市场日行情已经可用
  动作：系统执行每日数据更新
  结果：当日市场量价指标自动生成，首页最新数据日期和三项最新值随之更新

- AC-09：非交易日不生成结果
  前置：当日为周末或休市日
  动作：系统执行每日数据更新
  结果：跳过市场量价计算，不生成该自然日记录，并明确记录“非交易日”

- AC-10：日期范围校验
  前置：管理员位于“市场量价”同步页
  动作：分别提交开始日期晚于结束日期、结束日期晚于当前日期、所选范围内没有交易日三种输入
  结果：页面分别给出明确提示且均不创建同步任务；管理员修正为包含交易日的合法范围后可以正常启动同步

- AC-11：同步权限与任务互斥
  前置：场景一为普通用户尝试进入同步管理；场景二为已有市场量价同步任务正在运行
  动作：场景一直接访问同步管理入口；场景二管理员再次尝试启动同步
  结果：场景一不展示数据或操作并提示无权限；场景二“开始同步”不可用且展示当前任务进度，不创建第二个任务

- AC-12：首页加载失败后恢复
  前置：首页市场量价数据首次加载失败
  动作：用户点击“重试”，且数据服务已经恢复
  结果：失败提示消失，三项最新值和趋势图正常展示，用户无需刷新整个首页

- AC-13：停牌股票参与计算
  前置：某交易日应参与 A、B、C 三只股票；A 正常交易，B 盘中临时停牌但存在有效当日日行情，C 经确认为全天停牌且没有当日日行情，C 停牌前最近有效收盘价为 30 元
  动作：系统执行该交易日的市场量价同步
  结果：A、B 使用当日日行情正常计算；C 以收盘价 30 元、成交量 0、成交额 0 参与计算；完整性结果显示应参与 3 只、当日日行情 2 只、全天停牌 1 只、最终参与 3 只，并成功生成当日结果
