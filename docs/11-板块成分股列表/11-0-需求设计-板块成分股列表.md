# 11-0 需求设计：板块成分股列表

## 0. 文档说明

**产品核心目标**：让用户在分析某个板块强度走势的同时，一眼看到"是哪些股票撑起了这个板块"，并能继续下钻研究个股。

**本需求定位**：在已有的板块强度分析详情页基础上，补充"板块里都有哪些股票"这一缺失的信息层，打通"板块 → 个股"的下钻链路。

**相关文档**：
- 上游：板块强度分析（板块详情页）
- 下游（暂不实现）：个股分析页的深度功能（当前仓库不存在该页面，本期补齐最小落地页，见 1.4）

---

## 1. 需求分析与确认

### 1.1 项目背景

**产品当前状态**：用户从"板块分析列表"进入某个板块的详情页后，能看到该板块的强度历史曲线和均线分析两张图，判断板块整体强弱。

**存在的问题**：

1. **看不到"谁在驱动板块"**：板块强度是一个聚合数字，但用户无法知道这个分数是被哪几只龙头股拉高的，还是普遍偏强。需要拆解才能判断板块健康度。
2. **无法顺延研究个股**：用户在板块页看到一个强势板块，想去看里面具体股票时，没有入口，只能自己去行情软件搜代码，链路断裂。
3. **板块成分不可见导致无法验证判断**：用户怀疑某个板块强度异常时，无法快速核对成分股构成是否合理，只能凭板块名猜测。
4. **后端能力闲置**：系统已经具备"查询某板块成分股"的数据能力，但前端从未把它展示出来，能力与体验脱节。

**本期目标**：用户在板块详情页看完强度走势后，无需离开页面即可看到该板块的成分股明细（代码、名称、强度、最新价、市值、趋势），并能点击进入个股分析。

### 1.2 核心问题定义

| 问题 | 用户损失 |
|------|---------|
| 看不到板块成分股 | 无法判断板块强度是被龙头股拉动还是普遍走强，决策依据不完整 |
| 无法从板块下钻到个股 | 发现强势板块后要手动切到外部工具查成分股，效率低、易流失 |
| 无法核对板块构成 | 对板块强度数据存疑时无法自查，降低对数据的信任 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
|---------|---------|---------|---------|
| 列表放置位置 | 板块详情页图表区正下方 | 用户看完板块强度后自然想看"是哪些股撑起来的"，上下文紧邻，无需跳页 | 列表页底部（列表页展示全部板块，放单一板块成分股语义不通） |
| 列表初始排序 | 按强度分降序 | 用户来板块页就是看强弱，强度分是最关心的维度 | 按市值降序（市值反映体量而非当下强弱）、按代码序（无业务意义） |
| 可排序列 | 强度分、市值 | 这两项是用户判断成分股价值的核心维度，且后端已支持 | 最新价排序（价格绝对值跨股不可比，无分析意义） |
| 分页方式 | 传统分页 + 可切每页条数 | 成分股可达上百只，分页加载稳定可控，与项目内基金扎堆排行榜风格一致 | 无限滚动长列表（成分股量级未到必须该方案的程度，分页更直观） |
| 成分股点击行为 | 跳转个股分析页 | 延续"板块 → 个股"下钻链路，符合用户研究路径 | 仅展示不可点（信息孤岛，无法继续研究） |
| 个股分析页尚未实现时如何处理 | 本期含"跳转个股分析页"验收，路由页作为前置依赖需在本期一并补齐 | 否则点击会打开失败、体验断裂，验收无法通过 | 临时弹窗展示个股摘要（信息密度不够，且本期没有个股详情数据来源） |

### 1.4 产品范围

**本期范围**：

1. 板块详情页新增"板块成分股"区块，位于强度历史/均线分析两张图的下方。
2. 成分股列表展示列：股票代码、股票名称、强度分、涨跌趋势（升/平/降）、最新价、市值。
3. 列表支持按强度分、市值排序（升降序可切换），默认强度分降序。
4. 列表分页：支持翻页、切换每页条数。
5. 加载中、加载失败、空数据三种状态的标准呈现。
6. 点击成分股行可跳转到个股分析页。
7. 补齐个股分析页（当前仓库不存在该页面），作为成分股下钻的落地目标页；落地页需展示该个股的基础信息（代码、名称、当前强度分等），使跳转不致落空。个股分析页的详细功能不在本期展开。

**明确不做**：

- 个股分析页的深度功能（个股强度趋势图、均线分析、K线、资金流等），本期只提供可访问的最小落地页。
- 成分股在板块内的权重占比展示（后端当前不返回此字段）。
- 成分股的二级筛选（按行业、市值区间等过滤成分股）。
- 成分股列表的导出、收藏、加入自选股。
- 列表项的内嵌迷你走势图。

## 2. 用户旅程和用户故事

### 2.1 核心用户旅程

```text
进入板块详情页（看到强度历史 + 均线分析两张图）
        │
        ▼
向下滑动，看到"板块成分股"区块
        │
        ▼
浏览成分股列表（代码/名称/强度分/趋势/最新价/市值，默认按强度降序）
        │
        ├── 点击表头"强度分"或"市值" → 切换排序（升/降序）
        ├── 翻页 / 切换每页条数 → 看更多成分股
        │
        ▼
点击感兴趣的某只成分股行
        │
        ▼
跳转到该股的个股分析页，看到该股基础信息
```

**异常旅程**：

- **成分股加载失败**：列表区域显示失败提示与"重试"入口，不阻塞上方图表已有内容。用户可点击重试重新加载。
- **板块无成分股**：列表区域显示"该板块暂无成分股数据"的空态，引导用户先在数据管理页同步该板块成分股（仅文案提示，不做强制跳转）。
- **个股分析页加载失败**：跳转后落地页自身呈现失败态（属于个股分析页的处理范畴，本期不细化）。

### 2.2 用户故事

**核心用户故事**：

- 作为板块研究者，我希望在看板块强度走势的同时看到该板块的成分股明细，以便判断板块强弱是被哪些股票驱动的。
- 作为板块研究者，我希望能按强度分或市值给成分股排序，以便快速锁定板块内最强或最大的股票。
- 作为板块研究者，我希望能从板块里的某只成分股直接跳转到它的个股分析页，以便继续深入研究这只股票。

**延伸用户故事**：

- 作为板块研究者，我希望成分股列表能分页浏览，以便在成分股很多时也能稳定查看，不会一次加载过多。
- 作为板块研究者，我希望列表在加载中、加载失败时有明确提示，以便我知道当前状态、出错时能重试。

### 3.2 关键状态

| 状态 | 页面表现 | 用户下一步 |
|------|---------|-----------|
| 首次进入详情页 | 成分股区块显示骨架屏，上方图表区不受影响（各自独立加载） | 等待加载完成 |
| 加载成功（有数据） | 显示成分股表格，默认强度分降序，显示总数与分页器 | 浏览 / 排序 / 翻页 / 点击个股 |
| 加载成功（无数据） | 显示空态文案 | 去数据管理页同步成分股（用户自行操作） |
| 加载失败 | 显示失败提示 + 重试按钮 | 点击"重试"重新加载 |
| 排序中 | 切换排序后重新加载数据，列表显示加载态 | 等待新数据 |
| 翻页 | 列表滚动到区块顶部，显示新页数据 | 继续浏览 |

### 3.3 业务规则

**排序规则**：
- 初始排序：按强度分降序（强度高的在前）。
- 可排序列：强度分、市值。最新价、代码、名称、趋势列不可排序。
- 排序切换：点击当前排序列表头在"升序 ↔ 降序"间切换；点击另一可排序列表头则切到该列并默认降序。
- 表头排序方向用箭头指示当前列与方向（▼降序 / ▲升序），不可排序列的表头不显示箭头、鼠标移入无变化。

**分页规则**：
- 默认每页 20 条，支持切换为 50、100。
- 分页器展示"第 X/Y 页"、页码、每页条数选择、上一页/下一页。
- 仅当总数超过当前每页条数时才显示分页器；否则不显示分页器但仍显示"共 N 只"。
- 翻页或切换每页条数后，列表滚动到成分股区块顶部。

**数据呈现规则**：
- 趋势列用方向箭头 + 颜色区分：上升用红色 ▲、下降用绿色 ▼、持平用灰色 ▬（沿用项目内"红涨绿跌"的 A 股惯例）。
- 市值按量级简写显示（如"2.1万亿""6100亿"），并在数值后保留中文量级单位，便于横向比较。
- 最新价保留两位小数。
- 强度分取整数。
- 总数"共 N 只"始终显示，即使不足一页。

**跳转规则**：
- 点击成分股表格的任意一行，跳转到该股的个股分析页，跳转参数使用股票代码。
- 排序、分页等表头/分页器交互区不触发行跳转。

**降级呈现规则**：
- 成分股区块的加载与上方强度/均线图表相互独立：成分股加载失败不影响图表已有内容，图表加载也不阻塞成分股展示。
- 成分股区块自带的失败态提供"重试"按钮，仅重新加载成分股数据，不刷新整页。

## 4. 验收标准

- AC-01：板块成分股区块出现在详情页正确位置
  前置：从板块分析列表进入任意一个有成分股的板块详情页。
  动作：页面加载完成。
  结果：在强度历史图、均线分析图的下方出现"板块成分股"区块，显示成分股表格，数据按强度分降序排列，表格包含代码、名称、强度分、趋势、最新价、市值六列，并显示"共 N 只"总数。

- AC-02：按强度分排序
  前置：AC-01 已显示成分股列表。
  动作：点击表头"强度分"列。
  结果：列表切换为按强度分升序排列（强度低在前），表头出现升序箭头；再次点击切回降序，箭头随之变化。

- AC-03：按市值排序
  前置：AC-01 已显示成分股列表。
  动作：点击表头"市值"列。
  结果：列表切换为按市值降序排列，表头出现降序箭头；点击不可排序列（代码/名称/最新价/趋势）不触发排序变化。

- AC-04：分页浏览
  前置：进入一个成分股数量超过 20 只的板块详情页。
  动作：点击分页器第 2 页，并将每页条数切换为 50。
  结果：列表显示第 2 页数据；切换每页条数后重新从第 1 页开始展示，分页器总页数随每页条数变化而更新；翻页后页面滚动到成分股区块顶部。

- AC-05：加载失败可重试
  前置：成分股数据加载失败（如服务异常）。
  动作：页面加载。
  结果：成分股区块显示失败提示和"重试"按钮，上方强度/均线图表内容不受影响；点击"重试"后重新加载成分股数据。

- AC-06：空数据提示
  前置：进入一个没有任何成分股的板块详情页。
  动作：页面加载。
  结果：成分股区块显示"该板块暂无成分股数据"的空态文案，不显示表格和分页器。

- AC-07：点击成分股跳转个股分析页
  前置：AC-01 已显示成分股列表。
  动作：点击任意一只成分股所在行（非表头、非分页器区域）。
  结果：跳转到该股票的个股分析页，落地页能正常展示该股的代码、名称、强度分等基础信息，不出现页面无法访问或空白页。
