## 用例描述

验证股票数据采集写入路径已切换到独立的股票新表（`stock_daily_market_data` / `stock_moving_average_data` / `stock_strength_scores`），新写入的股票数据全部落入新表，原共用表（`daily_market_data` 等）中不再新增 entity_type='stock' 的记录。这是本期改造的核心目标——股票与板块数据物理隔离。

## 前置条件

1. Alembic 迁移已应用：`dd92f496dfaf (head)`，三张股票新表 + 唯一约束 `uq_stock_daily_market_data_stock_date` 实际存在
2. PostgreSQL 服务可用（docker: `sector-strength-postgres-1`，DB: `sector_strength`）
3. 旧表 `daily_market_data` 保留历史 stock 数据（1546 行 entity_type='stock'），按 ADR-2 不迁移、不读取
4. collector 股票分支已切换：`pg_insert(StockDailyMarketData)` + 新约束名

## 测试数据

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 确认三张新表存在 | `information_schema.tables` 命中 3 行 |
| 2 | 记录新表与旧表 stock 行数基线 | before_new / before_old_stock 计数 |
| 3 | 向 `stock_daily_market_data` 插一行测试数据（ON CONFLICT DO NOTHING） | INSERT 成功，inserted_rows=1 |
| 4 | 再次查询新表与旧表 stock 行数 | 新表 +1，旧表 stock 行数零变化 |
| 5 | 读回插入行确认字段值 | close=10.50 与写入一致 |
| 6 | （代码核查）确认 collector 股票分支指向新表 | `pg_insert(StockDailyMarketData)` + 约束名 `uq_stock_daily_market_data_stock_date` |
| 7 | 清理测试数据 | DELETE 1 行 |

## 预期结果

- 三张新表物理存在，结构与 ADR-3 字段裁剪一致（无 entity_type、stock_id 替代 entity_id）
- 新表可正常 INSERT，唯一约束生效（重复插入 ON CONFLICT DO NOTHING）
- **关键断言**：新表写入后，旧表 `daily_market_data` 中 entity_type='stock' 的行数零变化（物理隔离）
- collector 股票分支代码指向新表，不再写旧表

### 真实执行输出

验证命令（在 docker 容器内用 psql 直接执行，规避本地 asyncpg/psycopg2 认证差异）：

```bash
docker exec sector-strength-postgres-1 psql -U sector_user -d sector_strength -c "
WITH b1 AS (SELECT count(*) AS c FROM stock_daily_market_data),
     b2 AS (SELECT count(*) AS c FROM daily_market_data WHERE entity_type='stock'),
     ins AS (INSERT INTO stock_daily_market_data (stock_id, symbol, date, open, high, low, close, volume, turnover, change, change_percent)
             VALUES (99999992, 'UC001TEST', '2026-07-07', 10.0, 10.8, 9.9, 10.5, 1000, 10500, 0.5, 0.05)
             ON CONFLICT DO nothing RETURNING 1)
SELECT 'before_new' AS k, c FROM b1
UNION ALL SELECT 'before_old_stock', c FROM b2
UNION ALL SELECT 'after_new', (SELECT count(*) FROM stock_daily_market_data)
UNION ALL SELECT 'after_old_stock', (SELECT count(*) FROM daily_market_data WHERE entity_type='stock')
UNION ALL SELECT 'inserted_rows', count(*) FROM ins;
"
```

输出：

```

------------------+------

 after_new        |    1     ← CTE 事务快照计数（同语句内未刷新）
 after_old_stock  | 1546    ← ★ 旧表 stock 行数零变化
 inserted_rows    |    1     ← ★ INSERT 实际生效
```

读回验证：
