### 维度 4：实现规格符合度 — 通过

实读代码逐条核对 plan-02 §3 实现规格：

**Repository**（`broker_recommend_repository.py`）
- 继承 `BaseRepository[BrokerRecommend]` + `super().__init__(BrokerRecommend, session)`，与 FundCrowdRepository 范式一致。
- `get_months`：`select(BrokerRecommend.month).distinct().order_by(.desc())`，返回 `[row[0] for row in result.all()]`，范式参照 get_report_periods。
- `get_latest_month`：get_months 取首项，空返回 None（AC-10）。
- `get_stock_ranking`：主查询 `select(symbol, func.max(Stock.name), count(distinct broker)).select_from(BrokerRecommend).outerjoin(Stock, ...).where(month==month)`；search 时 `or_(symbol.like(escaped+'%'), Stock.name.ilike('%'+escaped+'%'))`（**OQ-escape 前缀/包含分离**）；`group_by(symbol).order_by(broker_count.desc(), symbol.asc()).limit(page_size).offset((page-1)*page_size)`（AC-07 双字段排序）；total 查询用同 where + group by symbol 子查询 `select(func.count())`（total=不同 symbol 数，AC-06）。与规格 #1 精确一致。
- `get_stock_brokers`：预加载（ADR-3）`select(symbol, broker, reason).where(month==month, symbol.in_(symbols))`，返回 `{symbol: [{broker, reason}]}`，空 symbols 返回 {}。
- `get_broker_list`：`select(broker, count(distinct symbol)).where(month==month)`，search 时 `broker.ilike('%'+escaped+'%')`，`group_by(broker).order_by(stock_count.desc(), broker.asc())`，total=不同 broker 数。与规格一致。
- `get_broker_detail`：`select(symbol, Stock.name, reason).select_from(...).outerjoin(Stock, ...).where(month==month, broker==broker)`（**broker 精确匹配 =，不做 LIKE**，避免误匹配，AC-13 安全），`order_by(symbol.asc())`。

**Service**（`broker_recommend_analysis_service.py`）
- 构造 `__init__(self, session): self.session = session; self.repo = BrokerRecommendRepository(session)`，范式参照 FundCrowdAnalysisService。
- `_get_industry_for_stocks`：显式 JOIN（`SectorStock.stock_code == Stock.symbol AND Sector.code == SectorStock.sector_code AND Sector.type == 'industry'`），**逐字复制** shareholder_analysis_service.py line 304-356 的 JOIN 逻辑，返回 `{symbol: {stock_name, industries}}`，传入缺失 symbol 补空结构。
- `_to_float`：Decimal→float，None 保持。
- `get_months`：has_data=len>0，months 转 ISO 字符串。
- `get_stock_ranking`：month 缺省 → get_latest_month，None → has_data=False 空结构（AC-09）；search strip + _escape_like_keyword；行业批量 JOIN + brokers 预加载聚合；items {symbol, name, industries, broker_count, brokers}（snake_case）；rows 空 → items=[]+total=0；返回含 has_data/month/items/total/page/page_size。
- `_aggregate_brokers`：同券商多 reason 归并到 `reasons: string[]`（去空去重不丢弃），LIMIT 100 兜底（MAX_BROKERS_PER_STOCK，ADR-3）。
- `get_broker_list`：同 latest_month 兜底，items {broker, stock_count}。
- `get_broker_detail`：month 解析 date，同 symbol 多 reason 合并去空去重，返回 {items:[{symbol, name, reasons}]}（AC-13）。

**路由**（`broker_recommend_analysis.py`）
- import 与规格 #3 一致（fastapi Query / pydantic BaseModel+ConfigDict+Field / to_camel / deps）。
- `router = APIRouter(prefix="/broker-recommend-analysis", tags=["BrokerRecommendAnalysis"])`（kebab-case，与 fund-crowd-analysis 一致）。
- `_serialize_value` + `_dict_to_camel`：**直接复制** fund_crowd_analysis.py line 104-129（Decimal→float, date→isoformat，递归 dict/list）。
- Pydantic models（StockRankingItem/BrokerBrief/BrokerGroupItem/BrokerDetailItem/RankingData/MonthsData/BrokerDetailData）均带 `ConfigDict(alias_generator=to_camel, populate_by_name=True)`，字段 snake_case 输出 camelCase。
- 4 端点：`/months`、`/stock-ranking`（month/search Optional + page/page_size）、`/broker-list`（同）、`/broker-detail`（month/broker 必填 Query(...)）。全部 `Depends(get_current_user)` 普通用户认证，query snake_case，响应 `{"success": True, "data": _dict_to_camel(result)}`。

**注册**（`__init__.py`）：line 23 `from .broker_recommend_analysis import router as broker_recommend_analysis_router` + line 41 `router.include_router(broker_recommend_analysis_router)`，范式参照 fund_crowd_analysis（line 21/39）。
