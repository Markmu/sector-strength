# 用例详情：UC-004 - 缺失检测与缺失日期范围展示

**Case ID:** UC-004
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P0
**创建日期:** 2026-05-27
**关联验收标准:** AC-02

## 用例描述

验证当某类数据最新日期早于今天且有交易日缺失时，卡片正确显示橙色"缺失"Badge 和缺失日期范围（YYYY-MM-DD ~ YYYY-MM-DD）。

## 前置条件

1. 以管理员身份登录系统
2. 后端 API 正常运行
3. 某类数据（如板块历史数据）的最新日期早于今天，且中间存在交易日
4. TradingCalendar 服务正常工作

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data | 页面加载完成 |
| 2 | 找到有缺失数据的卡片 | 卡片显示橙色"缺失"Badge（bg-amber-100 text-amber-700） |
| 3 | 检查最新日期 | 显示"最新日期：YYYY-MM-DD"（早于今天） |
| 4 | 检查缺失范围 | 显示"缺失范围：YYYY-MM-DD ~ YYYY-MM-DD"（橙色文字） |
| 5 | 检查补齐按钮 | 显示蓝色"补齐缺失数据"按钮 |

## 预期结果

- 橙色 Badge 标记"缺失"
- 缺失范围为最近交易日后的第一个交易日到最近一个交易日
- 日期格式为 YYYY-MM-DD
- 补齐按钮可见且可点击
