# 用例详情：UC-010 - 状态 API 请求失败显示错误态

**Case ID:** UC-010
**模块:** 数据状态标签页
**用例类型:** 异常
**优先级:** P1
**创建日期:** 2026-05-27
**关联验收标准:** AC-06

## 用例描述

验证状态 API 请求失败（网络超时、500 错误等）时，面板显示错误态和重试按钮。

## 前置条件

1. 以管理员身份登录系统
2. 后端 API 不可访问（停机、网络故障等）或返回错误

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 停止后端服务（或模拟 API 故障） | - |
| 2 | 访问 /dashboard/admin/data | 面板不显示骨架屏或卡片 |
| 3 | 观察错误态展示 | 显示红色 AlertCircle 图标 + 错误信息 |
| 4 | 检查重试按钮 | 显示蓝色"重试"按钮 |

## 预期结果

- 错误态居中展示在卡片区域
- 显示 AlertCircle 图标（红色）和错误信息文字
- "重试"按钮可见，带 RefreshCw 图标
- 不显示三张卡片
