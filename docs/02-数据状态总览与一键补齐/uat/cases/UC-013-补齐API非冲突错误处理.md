# 用例详情：UC-013 - 补齐 API 非冲突错误处理

**Case ID:** UC-013
**模块:** 数据状态标签页
**用例类型:** 异常
**优先级:** P2
**创建日期:** 2026-05-27
**关联验收标准:** AC-03

## 用例描述

验证补齐 API 返回非 409 错误（如 500、网络超时）时，按钮恢复可用且显示错误提示。

## 前置条件

1. 以管理员身份登录系统
2. 某类数据有缺失
3. 后端补齐 API 出现故障（如数据库连接异常）

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data | 缺失卡片显示补齐按钮 |
| 2 | 点击"补齐缺失数据"按钮 | 按钮禁用，发送 POST 请求 |
| 3 | 后端返回 500 错误 | 按钮恢复可用 |
| 4 | 检查页面状态 | 页面不崩溃，console 输出错误日志 |

## 预期结果

- 按钮从禁用态恢复为可用态
- 页面正常展示，不崩溃
- 错误信息输出到浏览器控制台
- 用户可以再次尝试点击
