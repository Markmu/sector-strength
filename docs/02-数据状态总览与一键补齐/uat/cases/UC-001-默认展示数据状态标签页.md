# 用例详情：UC-001 - 默认展示数据状态标签页

**Case ID:** UC-001
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P0
**创建日期:** 2026-05-27
**关联验收标准:** AC-01

## 用例描述

验证管理员打开数据管理页面时，默认进入"数据状态"标签页，且标签按钮处于激活状态。

## 前置条件

1. 以管理员身份登录系统
2. 后端 API 服务正常运行
3. 数据库中有 sector 类型的数据（或接受 no_data 状态）

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data | 页面正常加载，"数据状态"标签按钮可见 |
| 2 | 观察标签按钮状态 | "● 数据状态"标签按钮带有蓝色下划线，处于激活态 |
| 3 | 观察面板内容 | 数据状态面板可见（显示三张卡片或骨架屏加载态） |

## 预期结果

- "数据状态"标签在所有标签中的第一个位置
- 默认激活，蓝色下划线高亮
- 面板区域渲染 DataStatusPanel 组件
