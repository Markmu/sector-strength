# 用例详情：UC-011 - 点击重试重新请求状态 API

**Case ID:** UC-011
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P1
**创建日期:** 2026-05-27

## 用例描述

验证点击"重试"按钮后能重新请求状态 API，恢复正常展示。

## 前置条件

1. 以管理员身份登录系统
2. 当前面板处于错误态（UC-010 已触发）
3. 后端 API 已恢复正常

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 恢复后端服务 | - |
| 2 | 点击"重试"按钮 | 触发 mutate() 重新请求状态 API |
| 3 | 观察面板变化 | 错误态消失，显示骨架屏加载态 |
| 4 | 等待 API 响应 | 三张状态卡片正常展示 |

## 预期结果

- 点击重试后立即重新请求 API
- 加载态短暂显示后切换为正常卡片
- 三张卡片状态和数据正确
