# 用例详情：UC-003 - 数据表为空时显示暂无数据

**Case ID:** UC-003
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P1
**创建日期:** 2026-05-27
**关联验收标准:** AC-01

## 用例描述

验证某类数据表完全为空时，对应卡片显示"暂无数据"灰色 Badge，且不显示补齐按钮。

## 前置条件

1. 以管理员身份登录系统
2. 后端 API 正常运行
3. 至少一类数据表中无 sector 类型数据（如 strength_scores 表为空）

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data | 页面加载完成 |
| 2 | 找到无数据类型的卡片 | 卡片显示"板块强度数据"（或对应类型名） |
| 3 | 检查状态标记 | 显示灰色"暂无数据"Badge（bg-gray-100 text-gray-500） |
| 4 | 检查最新日期 | 不显示最新日期行（latest_date 为 null） |
| 5 | 检查补齐按钮 | 不显示补齐按钮 |

## 预期结果

- 灰色 Badge 标记"暂无数据"
- 无最新日期信息
- 无补齐按钮（与 missing 状态的关键区别）
