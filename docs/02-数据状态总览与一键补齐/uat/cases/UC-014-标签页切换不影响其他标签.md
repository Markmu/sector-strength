# 用例详情：UC-014 - 标签页切换不影响其他标签

**Case ID:** UC-014
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P1
**创建日期:** 2026-05-27
**关联验收标准:** 功能完整性

## 用例描述

验证"数据状态"标签页与现有标签页（数据初始化、均线计算、强度计算）之间切换正常，互不影响。

## 前置条件

1. 以管理员身份登录系统
2. 后端 API 正常运行
3. 现有标签页功能可用

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data | 默认展示"数据状态"标签页，三张卡片可见 |
| 2 | 点击"数据初始化"标签 | 切换到数据初始化面板，DataInitPanel 正常渲染 |
| 3 | 点击"板块均线计算"标签 | 切换到均线计算面板 |
| 4 | 点击"板块强度计算"标签 | 切换到强度计算面板 |
| 5 | 点击"● 数据状态"标签 | 切换回数据状态面板，三张卡片正常展示（重新加载） |

## 预期结果

- 所有标签页切换正常，无报错
- 切换到其他标签页时数据状态面板卸载
- 切换回数据状态标签页时重新加载数据
- 现有标签页功能不受新增标签页影响
