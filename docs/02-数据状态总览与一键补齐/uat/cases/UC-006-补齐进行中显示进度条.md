# 用例详情：UC-006 - 补齐进行中显示进度条

**Case ID:** UC-006
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P0
**创建日期:** 2026-05-27
**关联验收标准:** AC-03, AC-04

## 用例描述

验证补齐任务执行中，卡片显示进度条和百分比文字，每 2 秒自动刷新进度。

## 前置条件

1. 以管理员身份登录系统
2. 已触发一个补齐任务且任务正在执行（status=running）
3. 后端 TaskExecutor 正常更新进度

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data | 页面加载完成 |
| 2 | 找到有活跃任务的卡片 | 卡片显示进度条（蓝色容器 + 深蓝填充） |
| 3 | 检查进度百分比 | 显示百分比文字（如 "35%"） |
| 4 | 等待 2 秒 | 进度条和百分比自动更新（SWR refreshInterval） |
| 5 | 检查补齐按钮 | 补齐按钮不显示（被进度条替代） |

## 预期结果

- 进度条使用 div 宽度百分比渲染（progress / total * 100%）
- 进度条容器为 bg-blue-100，填充为 bg-blue-600
- 百分比显示在进度条右侧
- 每 2 秒自动刷新（SWR refreshInterval: 2000）
- 页面不可见时暂停轮询（SWR revalidateOnFocus）
