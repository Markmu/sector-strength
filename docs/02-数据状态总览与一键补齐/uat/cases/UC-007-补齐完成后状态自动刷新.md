# 用例详情：UC-007 - 补齐完成后状态自动刷新

**Case ID:** UC-007
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P0
**创建日期:** 2026-05-27
**关联验收标准:** AC-04

## 用例描述

验证补齐任务完成后，卡片自动从进度展示态切换为正常态，latest_date 已更新。

## 前置条件

1. 以管理员身份登录系统
2. 已触发一个补齐任务且任务正在执行
3. 补齐任务将在观察期间完成

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data，观察正在进行的补齐任务 | 卡片显示进度条 |
| 2 | 等待任务完成（轮询自动刷新） | 进度条达到 100% 后消失 |
| 3 | 观察卡片状态 | Badge 从"缺失"变为"正常"（绿色） |
| 4 | 检查最新日期 | 最新日期更新为补齐后的日期 |
| 5 | 检查轮询 | 无活跃任务后轮询停止（refreshInterval 变为 0） |

## 预期结果

- 任务完成后自动刷新，无需手动操作
- latest_date 更新为补齐数据后的最新日期
- 卡片状态从 missing → normal
- 进度条消失，Badge 变为绿色"正常"
- 轮询自动停止
