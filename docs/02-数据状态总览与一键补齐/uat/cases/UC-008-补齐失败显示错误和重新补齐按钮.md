# 用例详情：UC-008 - 补齐失败显示错误和重新补齐按钮

**Case ID:** UC-008
**模块:** 数据状态标签页
**用例类型:** 异常
**优先级:** P1
**创建日期:** 2026-05-27
**关联验收标准:** AC-05

## 用例描述

验证补齐任务失败时，卡片显示红色错误信息和"重新补齐"按钮。

## 前置条件

1. 以管理员身份登录系统
2. 有一个已失败的补齐任务（AsyncTask.status = "failed"，有 error_message）

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data | 页面加载完成 |
| 2 | 找到有失败任务的卡片 | 卡片显示红色错误信息（text-red-600） |
| 3 | 检查错误信息内容 | 显示后端返回的 error_message（如"补齐任务失败"） |
| 4 | 检查重新补齐按钮 | 显示蓝色"重新补齐"按钮 |

## 预期结果

- 错误信息为红色文字（text-red-600）
- 显示"重新补齐"按钮（蓝色，样式同补齐按钮）
- error_message 为 null 时显示默认文案"补齐任务失败"
