# 用例详情：UC-009 - 点击重新补齐再次创建任务

**Case ID:** UC-009
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P1
**创建日期:** 2026-05-27
**关联验收标准:** AC-05

## 用例描述

验证点击"重新补齐"按钮后能再次创建补齐任务，按钮进入禁用态。

## 前置条件

1. 以管理员身份登录系统
2. 有一个已失败的补齐任务，卡片显示"重新补齐"按钮

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 观察失败卡片的"重新补齐"按钮 | 按钮可点击 |
| 2 | 点击"重新补齐"按钮 | 按钮立即禁用，显示加载动画 |
| 3 | 观察网络请求 | 发送 POST /api/v1/admin/data/backfill/{type} |
| 4 | 等待 API 响应 | 返回成功，包含新 task_id |
| 5 | 观察卡片状态 | 卡片切换为进度展示态 |

## 预期结果

- 点击后按钮禁用，防止重复提交
- 创建新的补齐任务（新的 task_id）
- 卡片从失败态切换到进度展示态
- 后端允许为已失败的任务类型创建新任务
