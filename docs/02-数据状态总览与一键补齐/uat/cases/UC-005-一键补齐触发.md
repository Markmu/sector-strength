# 用例详情：UC-005 - 一键补齐触发

**Case ID:** UC-005
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P0
**创建日期:** 2026-05-27
**关联验收标准:** AC-03

## 用例描述

验证点击"补齐缺失数据"按钮后，自动检测缺口范围并创建补齐任务，按钮进入禁用态。

## 前置条件

1. 以管理员身份登录系统
2. 后端 API 和 TaskExecutor 正常运行
3. 某类数据有缺失（status=missing）
4. 该类型无活跃任务

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data | 页面加载完成，缺失卡片显示"补齐缺失数据"按钮 |
| 2 | 点击"补齐缺失数据"按钮 | 按钮立即变为禁用态（显示加载动画） |
| 3 | 观察网络请求 | 发送 POST /api/v1/admin/data/backfill/{type} |
| 4 | 等待 API 响应 | 返回 { success: true, data: { task_id: "..." } } |
| 5 | 观察卡片状态 | 卡片刷新后显示进度条（active_task 为 pending/running） |

## 预期结果

- 按钮点击后立即禁用，防止重复点击
- POST 请求成功，返回 task_id
- 状态自动刷新，卡片进入进度展示态
- 无需手动填写日期，后端自动检测缺口范围
