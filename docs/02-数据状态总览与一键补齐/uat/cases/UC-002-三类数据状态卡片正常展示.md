# 用例详情：UC-002 - 三类数据状态卡片正常展示

**Case ID:** UC-002
**模块:** 数据状态标签页
**用例类型:** 正向
**优先级:** P0
**创建日期:** 2026-05-27
**关联验收标准:** AC-01

## 用例描述

验证三类数据（板块历史数据、板块均线数据、板块强度数据）的状态卡片正常展示，包含数据类型名称、最新日期和状态标记。

## 前置条件

1. 以管理员身份登录系统
2. 后端 API 正常运行
3. 数据库中三类数据均存在且最新日期为最近交易日（status 为 normal）

## 测试数据

| 数据项 | 数据值 | 说明 |
|--------|--------|------|
| 数据类型 | history, ma, strength | 三类板块数据 |
| entity_type | sector | 板块类型 |

## 测试步骤

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 访问 /dashboard/admin/data | 页面加载完成 |
| 2 | 等待 API 响应 | 三张卡片分别显示"板块历史数据"、"板块均线数据"、"板块强度数据" |
| 3 | 检查每张卡片状态标记 | 每张卡片显示绿色"正常"Badge（深色背景白字） |
| 4 | 检查每张卡片最新日期 | 每张卡片显示"最新日期：YYYY-MM-DD"，日期为最近交易日 |

## 预期结果

- 三张卡片水平排列（桌面端 md:grid-cols-3）
- 每张卡片包含：标题行（类型名称 + Badge）、信息行（最新日期）
- 正常状态 Badge 为深色背景（bg-slate-700 text-white）
- 不显示补齐按钮
