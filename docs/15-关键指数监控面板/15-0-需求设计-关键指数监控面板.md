# 15-0 需求设计：关键指数监控面板

## 0. 文档说明

**产品核心目标**：为管理员提供关键指数的行情走势、估值水位与成分结构的实时监控分析面板，作为每日市场研判的入口。

**本需求定位**：基于第 14 期 ETF 监控与数据采集基建 + 新增宽基指数数据（行情/估值/权重）→ 用真实指数面板替换现有主页中模拟数据的市场强度模块，定位为管理员专属的市场研判首页。

**相关文档**：
- 第 14 期《ETF份额与资金流监控》— ETF 监控全链路，本面板通过跳转复用其资金流视角
- 第 13 期《板块资金流》— 板块资金流，主页移出的板块内容已有独立入口
- 第 03 期《数据源替换》— 数据源架构，指数数据采集复用既有数据源能力（相关指数数据接口已验证可用）

---

## 第一部分：需求分析与确认

### 1.1 项目背景

**产品当前状态**：平台已建成板块强度分析、板块资金流、ETF 资金流监控、股东分析等多模块分析体系，主页作为统一入口展示市场强度指数、板块热力图与排名列表。

**存在的问题：**

1. **主页"市场强度指数"是假数据**——现有市场强度模块使用随机数生成的模拟历史趋势数据，管理员看到的市场温度曲线不具任何参考价值，反而造成误导。
2. **缺少真实指数行情**——上证指数、沪深300、创业板指、科创50 等核心宽基指数的点位、涨跌幅、成交数据完全没有入库，管理员无法在平台内看到最基本的大盘行情。
3. **缺少估值监控**——PE/PB/换手率等估值指标是市场研判的核心，当前平台无任何估值数据，管理员需去第三方网站查看。
4. **指数与 ETF 资金割裂**——平台已有完善的 ETF 资金流监控（按跟踪指数聚合净流入），但缺少对应的指数行情面板，无法形成"指数点位 → 估值 → ETF 资金流入"的完整研判链路。
5. **指数成分不可见**——指数权重数据（如沪深300 前十大成分股）对理解指数涨跌驱动因素很重要，当前完全缺失。

**本期目标**：管理员登录后，主页直接呈现关键指数的真实行情走势、估值水位与成分权重，并能一键跳转对应 ETF 资金流，形成完整的指数研判工作台。

### 1.2 核心问题定义

| 问题 | 用户损失 |
|------|---------|
| 市场强度指数是随机模拟数据 | 管理员基于假数据做误判，对平台数据可信度产生怀疑 |
| 无法看到上证/沪深300 等核心指数行情 | 必须离开平台去第三方网站看大盘，工作流割裂 |
| 缺少 PE/PB 估值数据 | 无法判断当前市场估值处于历史高位还是低位，决策缺乏依据 |
| 指数行情与 ETF 资金流无联动 | 看到指数涨跌却不知道资金是流入还是流出，无法判断趋势可持续性 |
| 不知指数成分结构 | 指数涨跌时无法快速定位是哪些权重股驱动的 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
|---------|---------|---------|---------|
| 面板入口 | 替换主页内容 | 管理员每日第一件事就是看市场全局，指数监控应是最先映入眼帘的内容 | 新增侧边栏一级菜单（层级太深，不够首屏） |
| 可见性 | 仅管理员可见 | 指数估值/权重是专业分析数据，普通用户不需要；且数据同步有成本 | 全用户可见（无业务必要且增加数据成本） |
| 指数范围 | 全量可配置，预置14只 | 管理员关注点会变化，框架应支持灵活增减；预置14只覆盖主板/中小盘/科创/创业/北证 | 固定不可变（灵活性不足） |
| 估值覆盖 | 有数据的展示，无数据的提示"暂无" | 6只核心指数有完整估值，其余8只（科创/中证1000等）数据源本身不提供，如实展示即可 | 混合多数据源补齐（采集成本高、口径不一致） |
| 指数资金流 | 不做 | 数据源不提供指数级资金流；ETF 资金流已由第14期覆盖，面板跳转复用 | 按成分股权重聚合个股资金流（个股资金流未采集，成本过高） |
| 历史深度 | 近1年 | 足够做趋势/均线/分位分析，初始化快（分钟级），数据存储量可控 | 全量历史（初始化慢、首期用不到） |
| 板块热力图/排名 | 移至各自子页面入口 | 主页聚焦指数监控；板块分析、板块资金流已有独立侧边栏入口 | 全部塞在主页（信息过载） |

### 1.4 产品范围

**本期交付：**

1. **指数数据采集**——从数据源同步 4 类指数数据：基础信息（指数清单）、日线行情（开高低收/涨跌幅/成交）、每日估值指标（市盈率/市净率/换手率/市值）、成分股权重。
2. **指数数据管理（管理后台）**——在现有数据管理页新增"指数数据"Tab，集中提供两类管理操作：数据同步（指数清单同步、历史回填、当日采集，带实时进度和历史记录）与关注指数管理（增减关注指数，搜索全量清单勾选）。
3. **指数监控主页**——替换现有主页内容，展示：关注指数行情总览卡片、多指数走势对比图、估值水位图、成分权重表。
4. **ETF 联动跳转**——从指数卡片可跳转到 ETF 监控页查看对应资金流。
5. **每日自动更新**——交易日收盘后自动增量同步关注指数的数据。

**明确不做：**

- 指数级资金流向（数据源不提供，ETF 资金流归 ETF 监控模块）
- 指数成分股的个股资金流聚合（成本过高，后续迭代）
- 普通用户可见（仅管理员功能）
- 全球指数（该数据源暂不支持全球指数数据，暂不可用）
- 指数技术指标计算（MACD/KDJ 等，本期只做行情展示与估值水位，技术分析后续迭代）

## 第二部分：用户旅程和用户故事

### 2.1 核心用户旅程

**目标用户**：管理员（需要每日研判市场走势的资深使用者）

```
登录平台
  ↓
进入主页（原仪表板）
  ↓
看到「关键指数监控」面板
  ├─ 第一屏：关注指数行情总览卡片网格
  │    （上证指数/沪深300/创业板指/科创50 ... 收盘价、涨跌幅红绿、成交额、PE）
  │    ├─ 点击某指数卡片 → 展开/选中该指数的走势与估值
  │    └─ 点击卡片上「ETF 资金」→ 跳转 ETF 监控页（带该指数筛选）
  ↓
滚动查看分析区
  ├─ 多指数走势对比图（可选择多只指数叠加对比，支持归一化）
  ├─ 估值水位图（选中指数的 PE/PB 时间序列 + 当前分位标注）
  │    └─ 无估值数据的指数 → 显示「该指数暂无估值数据」提示
  └─ 成分权重表（选中指数的前 20 权重股 + 集中度）
       └─ 点击成分股 → 跳转个股分析页
  ↓
管理关注指数 / 数据同步（按需，跳转管理后台）
  └─ 进入数据管理页 →「指数数据」Tab
       ├─ 同步数据（清单/回填/当日采集）
       └─ 增减关注指数 → 保存后主页总览卡片和分析选项随之更新
  ↓
返回主页，完成当日市场研判，形成投资判断
```

**异常旅程：**

- **数据未初始化**：管理员首次进入主页时指数数据为空 → 展示空状态提示「请先同步指数数据」，引导至数据管理页的「指数数据」Tab。
- **当日数据未更新**：非交易日或数据未同步 → 总览卡片显示最近一个有数据的交易日，并在卡片角标注日期。
- **个别指数数据缺失**：某只指数行情拉取失败 → 该卡片显示「数据获取失败」，其余卡片正常展示，不互相影响。
- **估值数据不可用**：8 只无估值数据的指数 → 估值图区域显示「该指数暂无估值数据」，不影响其他功能。

### 2.2 用户故事

**核心用户故事：**

- US-01：作为管理员，我希望登录后主页直接看到上证/沪深300 等关键指数的真实涨跌行情，以便快速判断今日市场整体强弱，而不需要去第三方网站。
- US-02：作为管理员，我希望能对比多只指数的走势（如沪深300 vs 科创50），以便发现大小盘风格轮动趋势。
- US-03：作为管理员，我希望看到沪深300 等指数当前的 PE/PB 及其在近1年的分位水平，以便判断当前估值是偏高还是偏低。
- US-04：作为管理员，我希望能从某只指数一键跳转到跟踪该指数的 ETF 资金流监控页，以便判断指数涨跌背后的资金流向。
- US-05：作为管理员，我希望看到沪深300 的前十大成分股权重，以便指数大涨时快速知道是哪些股驱动的。

**延伸用户故事：**

- US-06：作为管理员，我希望能自由增减关注的指数（如加入中证1000、移出创业板综），以便面板只展示我关心的标的。
- US-07：我希望指数数据在每个交易日收盘后自动更新，以便次日早上看到的是最新行情。
- US-08：作为管理员，我希望在成分权重表中点击某只成分股跳转到个股分析页，以便进一步研究驱动指数的个股。
- US-09：作为管理员，我希望在首次使用前能手动同步指数清单并回填历史数据，以便主页有数据可展示。
- US-10：作为管理员，我希望在数据同步时看到实时进度（已完成/总量），以便判断还需要等多久。

### 2.3 数据初始化与关注管理旅程

主旅程依赖指数数据已入库。以下是首次使用前的数据初始化流程（在管理后台数据管理页的「指数数据」Tab 中完成）：

```
进入管理后台 → 数据管理页 →「指数数据」Tab
  ↓
步骤 1：同步指数清单
  └─ 点击「同步指数清单」→ 全量拉取交易所指数目录（约 1 万只）→ 完成
  ↓
步骤 2：管理关注指数
  └─ 在关注管理区搜索并勾选需要监控的指数（默认预置14只）→ 保存
  ↓
步骤 3：回填历史数据
  └─ 选择日期范围（默认近1年）→ 点击「开始回填」
       └─ 逐交易日采集：关注指数的行情 + 估值 + 权重
       └─ 进度条展示「回填中…（120 / 240 交易日）」
  ↓
步骤 4：验证主页数据
  └─ 返回主页 → 确认指数总览卡片有数据 → 初始化完成
```

日常运维时，管理员在同一页面执行当日增量采集或调整关注清单。

**异常旅程：**
- **同步中失败**：某交易日采集出错 → 进度条暂停并显示错误信息，可重试；已成功部分保留不丢失。
- **重复初始化**：清单/历史数据重复同步时，按交易日+指数代码去重覆盖，不产生重复记录。

### 3.2 关键状态

| 状态 | 页面表现 | 用户下一步 |
|------|---------|-----------|
| 数据正常 | 总览卡片展示最新交易日行情，走势/估值/权重图正常渲染 | 浏览分析、点击跳转 |
| 数据未初始化 | 全页面展示空状态提示 + 指数数据管理入口 | 跳转数据管理页「指数数据」Tab 完成初始化 |
| 当日未更新（非交易日/未同步） | 卡片显示最近有数据交易日，角标注日期 | 等待数据同步或手动触发 |
| 某指数行情失败 | 该卡片显示「数据获取失败」，其余正常 | 刷新或检查数据同步日志 |
| 选中无估值指数 | 估值区域显示「该指数暂无估值数据」提示 | 切换有估值的指数查看 |
| 非管理员访问主页 | 主页回退展示通用内容（板块强度入口等） | 无（普通用户不进入指数面板） |
| 同步任务运行中 | 对应操作按钮禁用并显示进度（已完成/总量） | 等待完成；其他操作按钮同时禁用 |
| 同步任务失败 | 进度条暂停并显示错误信息 | 点击重试；已成功部分保留 |

### 3.3 业务规则

**行情展示规则：**
- 涨跌幅 > 0 显示红色（中国市场惯例），< 0 显示绿色，= 0 显示灰色。
- 成交额以"亿元"为单位展示，超大数值自动缩写（如 12.1 亿）。
- 当日无数据时，卡片显示最近一个有数据交易日的行情，并在卡片右上角以小字标注该日期。

**估值展示规则：**
- 有估值数据的指数（上证指数/沪深300/上证50/中证500/深证成指/创业板指），卡片展示市盈率（TTM）值。
- 无估值数据的指数（中证1000/科创系列/创业板综/创业板50/科创创业50/北证50），卡片 PE 位置显示"暂无估值"，估值图区域显示提示文案。
- 估值分位数 = 当前值在近1年所有交易日数据中的百分位排名，以整数百分比展示（如"62%"）。

**走势对比规则：**
- 最少选择 1 只指数，最多选择 6 只指数同时对比。
- 归一化模式：以选择区间首日为基准（=100），展示相对变化，用于对比不同量级指数的相对强弱。
- 非归一化模式：展示真实点位，量级差异大的指数各自独立坐标轴区分。

**成分权重规则：**
- 权重数据为月度更新，展示最近一个月的权重快照。
- 默认展示前 20 名成分股，可切换为前 10 / 前 30。
- 集中度展示前 5 和前 10 成分股的权重合计占比。

**关注指数管理规则：**
- 初始预置 14 只主流指数（上证指数/沪深300/上证50/中证500/中证1000/深证成指/创业板指/创业板综/创业板50/科创50/科创100/科创200/科创创业50/北证50）。
- 关注管理位于管理后台数据管理页的「指数数据」Tab，与数据同步操作同页展示。
- 管理员可在全量指数清单中搜索并勾选/取消关注，保存后主页总览卡片和分析选项随之更新。

**ETF 跳转规则：**
- 点击指数卡片的「ETF 资金」按钮，跳转到 ETF 监控页，并自动筛选跟踪该指数的 ETF。

**数据同步规则：**
- 数据管理页「指数数据」Tab 提供三个同步操作：指数清单同步（全量拉取交易所指数目录）、历史数据回填（按日期范围逐交易日采集关注指数的行情/估值/权重）、当日增量采集（采集关注指数当日最新数据）。
- 同一时间仅允许一个同步任务运行，所有操作按钮共享互斥状态，任务进行中时其余按钮禁用。
- 同步任务实时展示进度（已完成数量/总量），完成后在底部同步记录表中留下记录（时间/操作类型/状态/详情）。
- 历史回填默认日期范围为近1年，管理员可自定义；按交易日升序逐日采集。
- 重复同步同一日期同一指数的数据时，按交易日+指数代码去重覆盖，不产生重复记录。
- 清单同步是其他操作的前置条件：清单未同步时，历史回填、当日采集和关注指数管理均禁用并提示"请先同步指数清单"。

## 第四部分：验收标准

- **AC-01**：主页指数数据初始化后总览展示
  前置：管理员已登录，指数数据已同步
  动作：进入主页
  结果：看到关注指数（≥14只）的总览卡片网格，每张卡片展示指数名称、收盘价、涨跌幅（红绿色区分）、成交额（亿元）；有估值的6只指数卡片展示市盈率（TTM），无估值的8只显示"暂无估值"

- **AC-02**：多指数走势对比
  前置：主页已展示指数总览
  动作：在走势对比区选择多只指数（如沪深300、科创50），切换归一化开关
  结果：图表展示所选指数的时间序列走势；归一化开启时以首日为基准对比相对强弱，关闭时展示真实点位

- **AC-03**：估值水位与分位
  前置：主页已展示指数总览
  动作：在估值水位区选择有估值的指数（如沪深300）
  结果：展示该指数市盈率（TTM）和市净率的时间序列曲线，并标注当前值在近1年的分位百分比；切换到无估值指数（如科创50）时显示"该指数暂无估值数据"提示

- **AC-04**：成分权重展示
  前置：主页已展示指数总览
  动作：在成分权重区选择有成分数据的指数（如沪深300），切换显示数量
  结果：展示前 N（10/20/30）成分股的名称、代码、权重百分比，底部展示前5/前10集中度占比

- **AC-05**：ETF 资金跳转
  前置：主页已展示指数总览
  动作：点击某指数卡片的「ETF 资金」按钮
  结果：跳转到 ETF 监控页，页面自动按该指数筛选展示对应 ETF 的资金流数据

- **AC-06**：成分股跳转个股分析
  前置：成分权重表已展示
  动作：点击表中某只成分股的跳转链接
  结果：跳转到该股票的个股分析页

- **AC-07**：关注指数管理
  前置：管理员进入数据管理页的「指数数据」Tab，指数清单已同步
  动作：在关注管理区取消关注某只指数并保存，返回主页
  结果：主页总览卡片移除该指数，走势/估值/权重的指数选择器同步移除该选项；再次在关注管理区勾选并保存后，主页恢复展示该指数

- **AC-08**：数据空状态
  前置：指数数据未同步
  动作：管理员进入主页
  结果：展示空状态提示"指数数据未初始化"并提供跳转数据管理页「指数数据」Tab 的入口

- **AC-08a**：指数清单同步
  前置：管理员进入数据管理页「指数数据」Tab，指数清单为空
  动作：点击"同步指数清单"按钮
  结果：全量指数目录拉取入库，进度实时展示；完成后历史回填和当日采集按钮变为可用；同步记录表新增一条"清单同步-完成"记录

- **AC-08b**：历史数据回填
  前置：指数清单已同步，历史数据为空
  动作：在数据管理页选择日期范围（近1年），点击"开始回填"
  结果：按交易日升序逐日采集关注指数的行情/估值/权重，进度条展示"回填中（N / 总量交易日）"；完成后主页指数数据可正常展示

- **AC-08c**：同步任务互斥与进度
  前置：某一同步任务正在运行
  动作：尝试点击其他同步操作按钮
  结果：其他按钮处于禁用状态；运行中的任务实时展示进度（已完成/总量），完成后按钮恢复可用

- **AC-08d**：同步任务失败与恢复
  前置：历史回填任务运行中，某一交易日采集出错
  动作：任务失败后查看错误提示，点击重试
  结果：进度暂停并显示错误信息；点击重试后从失败交易日继续，已成功部分保留不丢失；同步记录表新增对应失败/重试记录

- **AC-09**：真实数据验证（非模拟）
  前置：数据已同步
  动作：对比主页指数行情与数据源原始数据
  结果：收盘价、涨跌幅、市盈率（TTM）等数值与数据源一致，不含随机生成或模拟数据

- **AC-10**：每日自动更新
  前置：交易日收盘后数据同步任务已执行
  动作：次日管理员进入主页
  结果：总览卡片展示前一交易日的最新行情数据

- **AC-11**：非管理员不可见
  前置：普通用户（非管理员）登录
  动作：进入主页
  结果：不展示指数监控面板（展示通用内容或引导信息）

- **AC-12**：当日数据未更新时的降级展示
  前置：非交易日或当日指数数据尚未同步
  动作：管理员进入主页
  结果：总览卡片展示最近一个有数据交易日的行情，并在卡片右上角以小字标注该日期

- **AC-13**：个别指数行情失败时的隔离展示
  前置：某只指数行情数据获取失败
  动作：管理员进入主页
  结果：该指数卡片显示"数据获取失败"，其余指数卡片正常展示，互不影响
