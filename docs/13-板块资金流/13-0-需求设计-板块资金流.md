# 13-0 需求设计：板块资金流

## 0. 文档说明

**产品核心目标**：让用户一眼看到"今天的主力资金正在涌入哪些板块、流出哪些板块"，并能观察到盘中资金流入流出的实时变化趋势，用资金动向佐证板块强弱判断。

**本需求定位**：在已有的板块强度分析能力基础上，新增"板块资金流向"这一独立维度，让用户从"板块涨跌"延伸到"谁在用钱投票"，补全板块研究的资金面视角。本期包含两个互补的视图：当日资金流排行（看结果）和盘中资金流变化曲线（看过程）。

**相关文档**：
- 上游：板块强度分析（板块列表页、板块详情页）
- 数据来源：第三方财经数据接口（同花顺板块资金流），已实测可用

## 1. 需求分析与确认

### 1.1 项目背景

**产品当前状态**：用户在"板块分析"里能看到各板块的强度分排行、强度历史走势和均线分析，以此判断板块整体强弱和趋势。

**存在的问题**：

1. **只有价格强弱，看不到资金动向**：强度分反映的是板块涨跌表现，但"涨"不等于"有资金在流入"。用户无法判断一个走强的板块是真金白银买上去的，还是无量拉升，资金面信息完全缺失。
2. **无法横向对比哪些板块在被资金追逐**：用户想找"今天资金正在集中涌入的板块"时，没有现成的排行榜，只能凭涨跌幅猜，而涨跌幅与资金净流入并不一致（放量流出也能涨）。
3. **看不到盘中资金的动态变化过程**：即使知道某板块今日净流入，用户也无法判断资金是开盘一路买到现在，还是冲高后开始回落、或是午后突然异动。只有一个时点的快照数字，缺少"资金流入趋势"这层动态视角。
4. **行业与概念两个维度割裂**：资金炒作有时集中在行业（如"半导体"），有时集中在概念（如"锂电池"），用户无法在同一处切换查看两种维度的资金动向。
5. **外部工具与系统割裂**：用户要看板块资金流，只能切到行情软件，看完结论再回到本系统做强度分析，来回切换打断研究流程。

**本期目标**：用户在系统内打开一个独立的"板块资金流"页面，即可看到今日全市场板块的资金流入流出排行（行业/概念可切换），用净流入额排序锁定资金主攻方向；同时能看到自选板块在盘中资金净额的实时变化曲线，判断资金是持续流入、冲高回落还是突然异动；并能顺延跳到对应板块的强度详情页继续分析。

### 1.2 核心问题定义

| 问题 | 用户损失 |
|------|---------|
| 看不到板块资金动向 | 无法区分"真金白银的强势"和"无量虚涨"，板块强弱判断缺一层验证 |
| 没有资金流入流出排行 | 想找资金主攻板块时只能凭涨猜，而涨跌与资金净额常背离，容易误判 |
| 看不到盘中资金变化过程 | 只有一个时点的快照，无法判断资金是持续流入、冲高回落还是午后异动，错失盘中资金趋势信号 |
| 行业/概念资金流割裂 | 资金在不同维度流动，用户无法一处切换对比，漏看某一维度的机会 |

### 1.3 关键设计决策

| 决策维度 | 最终选择 | 核心理由 | 否决方案 |
|---------|---------|---------|---------|
| 数据呈现方式 | 独立的资金流页面，含排行表 + 盘中变化曲线两个视图 | 资金流是一个需要全局横向对比的维度，独立页面能让用户一次看清全市场资金分布；同时盘中曲线补全"过程"视角 | 挂在板块详情页（只能看单板块，无法横向对比） |
| 数据存储 | 盘中高频采样入库 + 收盘定稿 | 排行表需要最新快照、变化曲线需要完整时间序列，两者都入库后页面访问稳定快速、不依赖外部接口实时可用 | 每次访问实时调外部接口（慢、外部接口被限流时页面直接不可用，且无法回看历史采样） |
| 盘中采集策略 | 交易时段每 1 分钟采样一次、全板块采样 | 1 分钟粒度的曲线足够平滑地反映资金趋势；全板块采样保证事后任意板块都能画出曲线，不丢数据；已实测高频调用稳定（连续调用无风控） | 仅收盘采一次（无法画曲线）、只采前几名（事后想看其他板块没有数据） |
| 曲线展示方式 | 多板块净额叠加曲线，用户自选板块 | 用户最关心的是"对比几个重点板块谁的资金流入更持续"，叠加对比比单看一个板块更有价值；自选比固定前几名更灵活 | 单板块曲线（缺少对比）、固定前 5 不可改（不灵活） |
| 数据采集方式 | 定时采样 + 收盘定稿 + 管理员手动触发 | 盘中定时高频采样构建变化曲线，收盘后定稿保存当日最终值；沿用项目现有定时采集的成熟范式 | 完全手动触发（依赖人记得去点，盘中容易漏采、曲线断点） |
| 板块关联方式 | 按板块名称关联现有板块表 | 外部数据源与项目内板块分类来源不同，板块命名不完全一致，按名称松关联能最大化匹配又不会因命名差异丢数据 | 强制精确匹配代码（两套命名体系不同，匹配失败会大量丢数据） |
| 支持的板块维度 | 行业 + 概念 | 这两个是 A 股资金流最常用的分类维度，覆盖绝大多数用户需求；外部接口对这两个维度都已实测可用 | 同时做地域维度（用户使用频率低，优先级不足） |
| 排序默认值 | 按净流入额降序 | 净额是"流入比流出多多少"的直接体现，正负与大小一眼看出资金净方向，是资金流排行的核心指标 | 按涨跌幅排（涨跌是结果不是资金本身）、按总流入排（不看流出无法判断净方向） |
| 资金数值单位 | 亿元 | 与外部数据源口径一致，符合行情软件惯例，用户无需换算 | 按万元显示（数字过长不直观） |

### 1.4 产品范围

**本期范围**：

1. 新增"板块资金流"独立页面，入口位于主导航/侧边栏，与"板块分析"并列。页面包含两个视图：资金流排行表、盘中资金流变化曲线，可通过视图切换切换。
2. 页面提供"行业 / 概念"两个维度的切换标签，默认展示行业维度（两个视图共用此维度选择）。
3. **资金流排行视图**：展示列含排名、板块名称、板块涨跌幅、流入资金、流出资金、净额、公司家数、领涨股、领涨股涨跌幅。
4. 排行表默认按净额降序排列，支持按净额、流入资金、流出资金切换排序（升降序可切换）。
5. 排行表分页：支持翻页、切换每页条数。
6. 净额按正负色标呈现（正值红色、负值绿色，沿用项目"红涨绿跌"惯例）。
7. 日期切换：可查看历史已采集交易日的资金流排行，默认展示最新有数据的一天。
8. **盘中变化曲线视图**：以折线图展示所选板块在当日交易时段内的净额随时间变化曲线，支持多个板块叠加对比。
9. 曲线视图支持用户自选要叠加展示的板块（从当前维度下的板块列表中选取），多条曲线以不同颜色区分并配图例。
10. 曲线视图展示当日最新一条曲线；随盘中采样推进，用户手动刷新可看到曲线延长。
11. 板块名称可点击（排行表中），跳转到该板块现有的强度分析详情页（仅名称能匹配上现有板块表时才可跳转）。
12. 加载中、加载失败、空数据三种状态的标准呈现（两个视图各自独立）。
13. 后台定时采集板块资金流：交易时段每 1 分钟采样一次（构建变化曲线、刷新排行），收盘后定稿保存当日最终值，并支持管理员手动触发采集。

**明确不做**：

- 跨日的资金流历史趋势图（本期曲线只看单日盘中的变化；跨日对比需逐日快照入库后做日间趋势，列入后续需求）。
- 在板块详情页内嵌资金流模块（本期资金流是独立页面，不改造现有板块详情页）。
- 地域维度的资金流（使用频率低，留待后续）。
- 主力/超大单/大单/中单/小单的分级资金流细分（当前数据源不提供此细分，需换数据源）。
- 资金流数据的导出、收藏、加入自选。
- 资金流排行页内的板块强度分对比列（避免页面信息过载，强度分析在板块详情页查看）。
- 盘中曲线的服务端推送式自动刷新（本期曲线随用户手动刷新更新，不做服务端主动推送的实时更新）。

## 2. 用户旅程和用户故事

### 2.1 核心用户旅程

```text
从主导航进入"板块资金流"页面
        │
        ▼
看到行业维度的资金流排行表（默认按净额降序，正值红/负值绿）
        │
        ├── 切换"概念"标签 → 看概念维度的资金流排行
        ├── 切换排序（净额/流入/流出，升降序）→ 从不同角度找资金动向
        ├── 切换日期 → 看历史交易日的资金流
        ├── 翻页 / 切换每页条数 → 浏览更多板块
        │
        ▼
切换到"盘中变化"视图
        │
        ▼
看到资金流变化曲线图（默认展示当日净额，板块选择区为空待选）
        │
        ├── 从板块选择区勾选要对比的板块（可多选）→ 曲线叠加显示所选板块的净额变化
        ├── 刷新 → 看到曲线随盘中采样延长（盘中查看时）
        │
        ▼
（回到排行视图或离开页面）
        │
或：点击排行表里某个感兴趣的板块名称
        │
        ├── 名称能匹配现有板块 → 跳转到该板块强度分析详情页，继续研究
        └── 名称匹配不上 → 该名称不可点击，仅展示文字
```

**异常旅程**：

- **资金流加载失败**：当前视图区域显示失败提示与"重试"入口，用户可点击重试重新加载。
- **所选日期无数据**：当前视图区域显示"该日期暂无资金流数据"的空态，引导用户切换到其他日期或等待采集完成。
- **曲线视图无采样数据**：曲线区域显示"暂无盘中采样数据"空态（如非交易时段尚未开始采集、或采集未运行），引导用户在交易时段查看或联系管理员触发采集。
- **曲线视图未选择板块**：曲线区域显示"请选择要对比的板块"的引导提示，不展示空坐标系。
- **采集未运行导致无任何数据**：页面显示空态文案，提示该功能数据需要管理员触发采集（仅文案提示，不做强制跳转）。

### 2.2 用户故事

**核心用户故事**：

- 作为板块研究者，我希望在一个独立页面看到今日全市场板块的资金流入流出排行，以便快速锁定资金正在涌入的板块、流出哪些板块。
- 作为板块研究者，我希望能在行业和概念两个维度间切换查看资金流，以便从不同分类口径发现资金主攻方向。
- 作为板块研究者，我希望能按净额排序，并切换按流入或流出排序，以便从多个角度判断资金的净方向和绝对规模。
- 作为板块研究者，我希望能看到自选板块在盘中资金净额的实时变化曲线，以便判断资金是持续流入、冲高回落还是突然异动，捕捉盘中资金趋势。
- 作为板块研究者，我希望能把多个板块的净额变化曲线叠加对比，以便判断哪个板块的资金流入更持续、更有韧性。
- 作为板块研究者，我希望能从资金流排行里的某个板块直接跳到它的强度分析页，以便把"资金在买"和"板块走强"两层信息结合起来判断。

**延伸用户故事**：

- 作为板块研究者，我希望能切换查看历史交易日的资金流排行，以便复盘过去几天的资金动向变化。
- 作为板块研究者，我希望页面在加载中、加载失败时有明确提示，以便我知道当前状态、出错时能重试。
- 作为系统管理员，我希望能手动触发一次资金流采集，以便在定时任务未启用时也能及时拿到当日数据。

### 3.2 关键状态

| 状态 | 视图 | 页面表现 | 用户下一步 |
|------|------|---------|-----------|
| 首次进入 | 排行 | 表格区显示骨架屏，维度默认"行业"，视图默认"资金流排行" | 等待加载完成 |
| 加载成功（排行有数据） | 排行 | 显示排行表，默认净额降序，显示总数与分页器 | 浏览 / 切换维度 / 排序 / 切日期 / 翻页 / 点板块 / 切视图 |
| 加载成功（变化有数据） | 变化 | 显示曲线图与板块选择区；已选板块时显示叠加曲线 | 选板块 / 切维度 / 刷新看延长 |
| 排行所选日期无数据 | 排行 | 显示空态文案，提示切换日期 | 切换到其他日期 |
| 变化无采样数据 | 变化 | 显示"暂无盘中采样数据"空态 | 交易时段查看 / 联系管理员采集 |
| 变化未选板块 | 变化 | 显示"请选择要对比的板块"引导，不画空坐标系 | 添加板块 |
| 加载失败 | 两视图 | 显示失败提示 + 重试按钮 | 点击"重试"重新加载 |
| 切换维度/排序/日期/视图 | 对应视图 | 重新加载数据，显示加载态 | 等待新数据 |
| 翻页 | 排行 | 列表滚动到表格顶部，显示新页数据 | 继续浏览 |

### 3.3 业务规则

**视图切换规则**：
- 页面提供"资金流排行"和"盘中变化"两个视图标签，默认选中"资金流排行"。
- 维度切换（行业/概念）对两个视图都生效：排行视图展示该维度的板块排行，变化视图的板块选择区列出该维度的板块。
- 切换视图时维度与日期维持当前选择；已选对比板块在切换视图后保留（回到变化视图仍记得用户选了哪些）。

**维度切换规则**：
- 提供"行业""概念"两个标签，默认选中"行业"。
- 切换维度后重新加载该维度下的数据；排行视图的排序、日期、页码维持当前选择（若当前页码超出新数据总页数则回到第 1 页）；变化视图的已选板块若在新维度下不存在则自动移除。

**排序规则**（排行视图）：
- 初始排序：按净额降序（净流入多的在前）。
- 可排序列：净额、流入资金、流出资金。排名、板块名称、涨跌幅、公司家数、领涨股列不可排序。
- 排序切换：点击当前排序列表头在"升序 ↔ 降序"间切换；点击另一可排序列表头则切到该列并默认降序。
- 表头排序方向用箭头指示当前列与方向（▼降序 / ▲升序），不可排序列的表头不显示箭头、鼠标移入无变化。

**日期切换规则**：
- 日期选择器默认定位到"最新有数据的交易日"，用户可切换到其他已采集过的交易日。
- 仅允许选择库中已有数据的日期；若用户选了一个无数据的日期（如非交易日或未采集），显示空态而非报错。
- 切换日期后，维度、视图维持当前选择。
- 变化视图切换日期后，曲线展示所选交易日的盘中采样序列（历史交易日也能回看当日盘中变化）。

**分页规则**（排行视图）：
- 默认每页 20 条，支持切换为 50、100。
- 分页器展示"共 N 个板块"、页码、每页条数选择、上一页/下一页。
- 翻页或切换每页条数后，列表滚动到表格顶部。

**变化曲线规则**（变化视图）：
- 曲线横轴为当日交易时段时间（约 9:30-15:00），纵轴为净额（亿元）。
- 每条曲线对应一个所选板块，以不同颜色区分，配图例（颜色 + 板块名 + 当前最新净额）。
- 净额零轴以基线标出，曲线上穿/下穿基线直观反映资金由净流出转净流入或反之。
- 用户通过板块选择区添加/移除对比板块，曲线即时增减对应线条。
- 盘中查看时，用户点击"刷新"可拉取最新采样点，曲线延长；本期不做自动推送刷新。
- 当所选板块在当日有采样数据但数据点较少（如刚开盘）时，曲线正常绘制已有部分，不报错。

**数据呈现规则**：
- 净额、流入资金、流出资金以"亿元"为单位显示，保留两位小数。
- 净额按正负色标：正值红色（带正号或无符号）、负值绿色（带负号）；流入、流出资金为绝对值，统一中性色。
- 板块涨跌幅、领涨股涨跌幅按正负色标（涨红跌绿），带百分号。
- 领涨股名称前若带"\*"（表示风险警示股）原样显示。
- 排名列按当前排序结果顺序编号（净额降序时第 1 名即净流入最多）。

**跳转规则**：
- 板块名称列（排行视图）：仅当该板块名称能与现有板块表匹配上时，名称显示为可点击链接样式；点击后跳转到该板块的强度分析详情页，跳转参数使用板块标识。
- 名称匹配不上的板块，名称显示为普通文字，不可点击。
- 排序、分页、日期切换等表头/分页器交互区不触发行跳转。
- 变化视图的板块选择区和曲线图例不触发跳转。

**降级呈现规则**：
- 页面数据来自已入库的采集快照，不实时依赖外部接口：即使外部数据源临时不可用，只要库里有数据，页面照常展示。
- 当所选日期完全无数据时，给出口径明确的空态文案，不展示空白表格或空坐标系。
- 两个视图各自独立加载：一个视图加载失败不影响另一个视图已有内容。

## 4. 验收标准

- AC-01：资金流页面可从导航进入并默认展示行业排行
  前置：系统中已采集到当日（或最近交易日）的板块资金流数据。
  动作：从主导航进入"板块资金流"页面。
  结果：页面加载完成，默认处于"资金流排行"视图、"行业"维度，显示资金流排行表，数据按净额降序排列，表格包含排名、板块名称、涨跌幅、流入、流出、净额、公司家数、领涨股、领涨股涨跌幅等列，净额正值红色、负值绿色，底部显示"共 N 个板块"与分页器；页面顶部同时可见"盘中变化"视图入口。

- AC-02：行业/概念维度切换
  前置：AC-01 已显示行业维度排行。
  动作：点击"概念"标签。
  结果：表格切换为概念维度的资金流排行，数据量与行业维度不同（概念通常更多），排序仍为净额降序；再点回"行业"标签能切回。

- AC-03：按净额/流入/流出排序切换
  前置：AC-01 已显示资金流排行。
  动作：依次点击表头"流入""流出""净额"列。
  结果：点击"流入"列切换为按流入资金降序排列并显示降序箭头；点击"流出"列切换为按流出资金降序；点击"净额"列切回净额降序；点击当前列再次可切换为升序，箭头随之变化；点击不可排序列（排名/板块名称/涨跌幅等）不触发排序。

- AC-04：切换日期查看历史排行
  前置：系统中已采集多个交易日的资金流数据。
  动作：在日期选择器切换到一个历史交易日。
  结果：表格显示该日期的资金流排行，排序与维度维持当前选择；切换到一个无数据的日期（如非交易日）时，表格区显示"该日期暂无资金流数据"空态而非报错。

- AC-05：切换到盘中变化视图并展示叠加曲线
  前置：当日（或所选交易日）交易时段已有盘中采样数据。
  动作：进入"板块资金流"页面，点击"盘中变化"视图标签。
  结果：页面切换到变化视图，显示板块选择区和曲线图区；进入时若未选板块则显示"请选择要对比的板块"引导提示，不画空坐标系。

- AC-06：选择板块叠加净额变化曲线
  前置：AC-05 已进入变化视图，且当日有盘中采样数据。
  动作：在板块选择区添加 2-3 个板块。
  结果：曲线图区以不同颜色叠加显示所选板块的净额变化曲线，横轴为交易时段时间、纵轴为净额（亿元），配图例标注每个板块名称与颜色；零轴有基线；移除某板块后对应曲线消失。

- AC-07：盘中刷新曲线延长
  前置：当前为交易时段，盘中采样正在进行，AC-06 已显示当日曲线。
  动作：等待约 1 分钟后点击"刷新"。
  结果：曲线在原有基础上向右延长，末端出现新的采样点；曲线起点和已有部分不发生回缩或突变。

- AC-08：变化视图无采样数据与历史回看
  前置：选择了一个无任何盘中采样数据的日期（如采集未运行的非交易日）。
  动作：进入变化视图并尝试选择板块。
  结果：曲线区显示"暂无盘中采样数据"空态，不显示空坐标系；切换到一个有采样数据的历史交易日后，曲线正常显示该日的完整盘中变化序列。

- AC-09：加载失败可重试
  前置：资金流数据加载失败（如服务异常）。
  动作：页面加载（排行或变化视图均可）。
  结果：当前视图区域显示失败提示和"重试"按钮；点击"重试"后重新加载该视图数据。

- AC-10：点击板块名称跳转强度分析页
  前置：AC-01 已显示资金流排行，其中存在名称能与现有板块表匹配的板块。
  动作：点击一个可匹配的板块名称。
  结果：跳转到该板块的强度分析详情页，落地页正常展示该板块的强度历史/均线分析等已有内容，不出现页面无法访问；名称匹配不上的板块名称不可点击（普通文字样式），点击无反应。

- AC-11：管理员可手动触发采集
  前置：当前为交易日，定时采集未自动运行。
  动作：管理员在数据管理后台手动触发一次板块资金流采集。
  结果：采集完成后，资金流页面能查到本次采集的当日数据（排行与变化视图均有更新）；采集过程中页面已有的历史数据不受影响。

- AC-12：分页浏览
  前置：进入行业维度资金流排行（板块数超过 20）。
  动作：点击分页器第 2 页，并将每页条数切换为 50。
  结果：列表显示第 2 页数据；切换每页条数后从第 1 页重新展示，分页器总页数随每页条数更新；翻页后页面滚动到表格顶部。
